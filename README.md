# NowPilot

The All-in-One Productivity Extension for ServiceNow Support Engineers.

NowPilot is a privacy-first Chrome extension (Manifest V3) for support engineers.
It provides a Chat-only Side Panel and a full Standalone workspace, with
workspace handoff, a provider-neutral AI runtime, local-first notes and memory,
governed tools, and a ServiceNow integration. It does not modify host-page UI in
v0.1.
