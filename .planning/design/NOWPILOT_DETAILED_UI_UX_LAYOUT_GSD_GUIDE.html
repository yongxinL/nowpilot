NowPilot Detailed UI/UX Layout and GSD Guide

Concrete screen blueprints, workflow-based model routing, Google AI Studio instructions, and autonomous OpenCode + GSD execution guidance.

Model selector decisionLayoutsOptionsImplementation

Decision: remove the raw model selector from Chat

Recommended: show a Workflow selector, not a model selector. Each workflow defines its capability tier, tools, context and confirmation behaviour; TierResolver chooses the concrete provider/model.

A model selector would let the user override workflow requirements and could select a model that lacks the required tools or context. It also exposes infrastructure detail during a task-focused conversation.

What the user sees

  • Workflow: Auto, Ask, Write, Research, Summarise page, ServiceNow case analysis.
  • Read-only transparency: resolved provider/model in Activity details and Diagnostics.
  • Configuration: provider/model enablement and workflow-to-tier mapping in Standalone Options.
  • Failure: a typed “No compatible model configured” result with a direct Options action.

Interaction and state standards

StateRequired presentation
LoadingSkeleton approximating final geometry, plus text for long operations.
EmptyOne explanation, one primary action, optional examples.
ErrorHuman-readable message, typed detail, Retry, and the relevant settings action.
StreamingStable assistant container, Stop control, no typewriter animation.
PermissionDescribe action, target and impact; Allow once, Allow always where safe, and Deny.
SavedText plus icon/colour. Never colour alone.

Accessibility

  • WCAG AA contrast in every theme pack and colour mode.
  • Visible focus and complete keyboard operation.
  • Icon-only buttons require tooltip and accessible name.
  • Sheets, drawers and modals trap focus and restore it on close.
  • Honour reduced motion and reduced transparency.

Implement the exact example layouts in NOWPILOT_DETAILED_UI_UX_LAYOUT_GSD_GUIDE.html. The composer uses a Workflow selector, not a raw model selector. OpenCode + GSD instruction

Treat PRODUCT_SPEC_v0_2.md, DESIGN_SYSTEM_v0_2.md and NOWPILOT_DETAILED_UI_UX_LAYOUT_GSD_GUIDE.html as the approved baseline. Do not repeat product planning or architecture design. Validate consistency, map the imported UI seed, create the minimum WXT conversion plan, and execute automatically. Ask only when a genuine unresolved product decision remains. The raw model selector is prohibited in Chat; implement workflow selection and automatic TierResolver routing instead.

Cost-effective model execution

Use GSD's inherit profile and the best cost-effective model available in OpenCode. Keep tasks small, IDs closed, TypeScript strict, verification executable, repairs limited to two, and commits atomic.
