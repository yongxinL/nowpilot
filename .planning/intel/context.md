## Topic: Model selector decision (embedded decision)
- source: .planning/design/NOWPILOT_DETAILED_UI_UX_LAYOUT_GSD_GUIDE.html
- content: Section "Decision: remove the raw model selector from Chat". Verbatim callout: "**Recommended:** show a Workflow selector, not a model selector. Each workflow defines its capability tier, tools, context and confirmation behaviour; `TierResolver` chooses the concrete provider/model." Rationale given: a model selector would let the user override workflow requirements and could select a model that lacks the required tools or context; it also exposes infrastructure detail during a task-focused conversation. What the user sees: Workflow = Auto, Ask, Write, Research, Summarise page, ServiceNow case analysis; read-only transparency = resolved provider/model in Activity details and Diagnostics; configuration = provider/model enablement and workflow-to-tier mapping in Standalone Options; failure = typed "No compatible model configured" result with a direct Options action. Tags: "Intent visible · Model automatic · Cost governed · Fallback deterministic". This decision is corroborated by PRODUCT_SPEC (Line "UI Seed and Workflow Routing Authority", §9.1, §9.3a, §17.1c, Appendix D) and by DESIGN_SYSTEM §8.1g.

## Topic: Interaction and state standards
- source: .planning/design/NOWPILOT_DETAILED_UI_UX_LAYOUT_GSD_GUIDE.html
- content: Table verbatim — Loading: "Skeleton approximating final geometry, plus text for long operations." Empty: "One explanation, one primary action, optional examples." Error: "Human-readable message, typed detail, Retry, and the relevant settings action." Streaming: "Stable assistant container, Stop control, no typewriter animation." Permission: "Describe action, target and impact; Allow once, Allow always where safe, and Deny." Saved: "Text plus icon/colour. Never colour alone." Consistent with PRODUCT_SPEC §12/§17.4 and DESIGN_SYSTEM §8.9.

## Topic: Accessibility standards
- source: .planning/design/NOWPILOT_DETAILED_UI_UX_LAYOUT_GSD_GUIDE.html
- content: WCAG AA contrast in every theme pack and colour mode; visible focus and complete keyboard operation; icon-only buttons require tooltip and accessible name; sheets, drawers and modals trap focus and restore it on close; honour reduced motion and reduced transparency. Consistent with PRODUCT_SPEC §17.6 and DESIGN_SYSTEM §12.
