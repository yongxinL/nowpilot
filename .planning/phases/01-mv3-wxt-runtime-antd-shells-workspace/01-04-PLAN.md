<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ThemeStore (chrome.storage.sync) ↔ Render surfaces | Theme mode crosses between surfaces via shared chrome.storage.sync — a corrupted mode value could render unreadable UI |
| WorkspaceStore (chrome.storage.session) ↔ Render surfaces | Workspace state handed off from Side Panel to Full App through shared session storage |
| Popup → Side Panel / Full App | Popup triggers navigation to other surfaces via chrome.sidePanel.open() and openFullApp() |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|------------------|
| T-04-THEME | Denial of Service | ThemeStore | low | accept | ThemeStore stores only `{ mode }` — 12 bytes max. chrome.storage.sync corruption would affect only the theme (cosmetic). Defaults to 'auto' on read failure. No data loss or security impact. |
| T-04-HANDOFF | Information Disclosure | workspaceRouter.ts | low | accept | Workspace handoff writes workspaceId/conversationId to chrome.storage.session which is cleared on extension disable/reload. Data exposure scope is limited to the user's own browser session. |

**Threat disposition summary:** 2 threats — 2 accepted (both low severity, cosmetic/transient), 0 mitigated, 0 transferred.
</threat_model>
