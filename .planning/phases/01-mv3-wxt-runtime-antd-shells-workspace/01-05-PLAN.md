<objective>
Make `np_theme` a genuine single source of truth and give both surfaces a derivation function they can call.

Purpose: APPR-03 is currently false. `ThemeStore`'s zustand `persist` writes a JSON blob to `np_theme` while `applyThemeToSync` writes a bare mode string to the same key, and the `onChanged` handler casts whatever arrives straight to `ThemeMode` — so toggling on one surface flips the other back, and the prototype's own tests codify the wrong contract. Separately, `getAntdConfig({ mode, pack, compact })` does not exist: the only theme factories ignore their pack argument. This plan makes one writer, one representation, one derivation point, and proves it with a two-surface round trip against the real persisted shape.
Output: one owner of `np_theme`, a tolerant reader, an `onChanged` propagation path, pack-ready `getAntdConfig` with the per-surface algorithm split, the local-first failure toast, and the `cycleThemeMode()` the palette command calls.
</objective>
