<objective>
Land the single fixture/deferred marking convention and apply the deterministic non-Phase-1 page disposition across every preserved page and surface panel.

Purpose: D-16 requires that every non-Phase-1 page carry exactly one disposition — preserved presentation rendered from deterministic local fixtures, or a canonical shell with an intentional deferred panel naming its owning roadmap phase, or removal — and forbids both the ambiguous middle and the perpetual skeleton. The prototype already carries a prose sentence saying a page arrives in a later phase, but it has no machine-checkable marker and it uses a bare empty state the design system forbids. This plan gives the rule one component, one type, one greppable DOM attribute and presence/absence tests, then applies it page by page from the frozen inventory.
Output: `DeferredNotice` and `Phase1Backing`; every page and surface panel marked or removed per its inventory disposition; and a page-level suite asserting both the marker and its absence where the page is live.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| fixture data → production surfaces | Fixture-derived values must never reach a persistent store, a message, an export or a screenshot fixture. |
| deferred UI → user expectation | A control that looks live but cannot work is a misrepresentation of the runtime's capability. |
| marker attribute → audit fidelity | The marker is the only machine-checkable evidence that the disposition was applied; a false or missing marker hides a real gap. |
