## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| store schema → persisted blob | A persisted blob written by an older version carries removed fields; the migration is the boundary that must drop them. |
| removed provider service → importers | Removing an export while an importer remains is a build-time break, and re-adding the export to make the build pass would reintroduce the credential path. |
| build configuration → generated bundle | After the script redirect, the build configuration decides what can enter the extension bundle. |
