**Step A — install and configure.** Add `@wxt-dev/module-react@^1.2.2` as a devDependency (`pnpm add -D @wxt-dev/module-react@^1.2.2`). Do not touch `antd`, `@ant-design/x`, `@ant-design/x-markdown`, `@ant-design/icons`, `zod`, `motion`, `vite` or `vitest` versions in this plan — any version bump is out of scope and requires its own checkpoint. In `wxt.config.ts` set `srcDir: 'src'` and `modules: ['@wxt-dev/module-react']`, keep `webExt: { disabled: true }`, keep `dev.server` and the existing `vite.build` block, keep `permissions: ['sidePanel','storage','tabs']` and the existing ServiceNow `host_permissions`, keep `side_panel.default_path: 'sidepanel.html'`, and delete the `options_ui` and `options_page` keys entirely (an `options_ui` key silently forces `"open_in_tab": false` into the generated manifest). Record the CSP decision line in the inventory's `Resolved hand-off decisions` section. `publicDir` and `modulesDir` stay at the repository root and need no configuration change (WXT resolves both against `root`, not `srcDir`).

**Step B — relocate.** `git mv` the four entrypoint groups: `entrypoints/background.ts` → `src/entrypoints/background.ts`; `entrypoints/sidepanel/{index.html,main.tsx}` → `src/entrypoints/sidepanel/`; `entrypoints/standalone/{index.html,main.tsx}` → `src/entrypoints/standalone/`; `entrypoints/content/core.content.ts` → `src/entrypoints/content/index.ts`. The content-script rename is mandatory, not cosmetic: WXT resolves content scripts against the globs `content.[jt]s?(x)`, `content/index.[jt]s?(x)`, `*.content.[jt]s?(x)`, `*.content/index.[jt]s?(x)` with `expandDirectories: false`, and `core.content.ts` matches none of them while `content/index.ts` matches the second. Keep the entrypoint directories self-contained (HTML, main module and entrypoint-specific assets together); no loose supporting files directly under `src/entrypoints/`. Leave `entrypoints/options/**` in place — its removal is plan `01-11`'s row.

**Step C — repoint paths.** In `tsconfig.json` change `paths` to `{ "@/*": ["./src/*"], "~/*": ["./src/*"] }` and drop the root `entrypoints/**/*` entry from `include` (`src/**/*` now covers it). Keep `.wxt/` on disk — it is regenerated by `wxt prepare`, and hand-editing it is forbidden.

**Step D — author the provider root and the shells (the thin slice).** Create `src/core/theme/antdConfig.ts` exporting `getAntdConfig({ mode, pack, compact }: { mode: ThemeMode; pack: ThemePack; compact: boolean }): ThemeConfig`. It must always return an object — never `undefined`, because AntD changes the provider tree identity and remounts children when `theme` flips between `undefined` and an object — and it must compose `algorithm` as an array: `[resolved === 'dark' ? theme.darkAlgorithm : theme.defaultAlgorithm]` with `theme.compactAlgorithm` pushed only when `compact` is true. Set `cssVar: true` and `locale: enUS` (imported from `antd/locale/en_US`), so no AntD locale default is reachable.
