## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| chrome.storage.session (writer) ↔ chrome.storage.session (reader) | Multiple surfaces read workspace state — a rogue writer could corrupt shared state |
| chrome.tabs API ↔ WorkspaceRouter | Tab creation/de-duplication logic — incorrect URL matching could open wrong tabs |
| add-on code ↔ PageRegistries | In Phase 8, third-party add-ons will call register() on these registries |

| T-03-ELEV | Elevation of Privilege | src/core/ | medium | mitigate | ADDON-10: Core directory structure (`src/core/`) never imports from `src/addons/`. Enforced by ESLint no-restricted-imports rule (Plan 01-01). Registries receive registrations (push model) — add-ons depend on core, never the reverse. |
| T-03-DUP | Denial of Service | workspaceRouter.ts | low | accept | Tab deduplication handles multiple existing tabs by focusing only the first. Acceptable — Chrome rarely creates duplicate extension tabs unless the user manually duplicates. |
