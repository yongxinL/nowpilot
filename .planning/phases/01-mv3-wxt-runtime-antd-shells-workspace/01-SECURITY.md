## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Page (host) → extension content script | Phase 1 ships no content script in the build (01-03 Option C); the staged file is extraction-only, has no fetch/UI/host-write and no host match beyond the authorised ServiceNow set | None in Phase 1 |
| Extension contexts → background SW | MV3 message boundary: every cross-context message carries RuntimeEnvelope<T>, strict per-type Zod validation, fail-closed sender guard (sender.id === chrome.runtime.id) | Envelope payloads (no credentials) |
| chrome.storage.local (legacy) → cleanup | Legacy plaintext provider credentials are destroyed in place on install/startup; report is field-names-only and the notice discloses nothing | Secret values (deleted; never returned/logged/derived) |
| Side Panel ↔ Standalone | Request-correlated ready/transfer/ack handoff; allowlist URL projection; no draft in URL/storage/bus/log | Workspace state projection + ephemeral composer draft |
| Source/build → shipped bundle | Least-privilege manifest pinned by a read-only inspection test; no options key; CSP connect-src none; banned-import + no-tailwind + strict-ceiling gates | Production bundle + manifest |
| Phase gate → acceptance claim | Explicit path list + resolution preflight; non-zero scan counts; observed-result rule for browser-only criteria | Verification evidence |
