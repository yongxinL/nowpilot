## @mention Syntax & Scope

| Option | Description | Selected |
|--------|-------------|----------|
| All three as specified | @note, @tab, @prompt — full spec | ✓ |
| Notes + tabs only | Skip @prompt | |
| Notes only | @note only | |

**User's choice:** Unified Reference System with three initial entity types: @note (NotesDB), @tab (workspaceStore pinned tabs), @prompt (PromptManager templates). Mentions should render as inline chips within the Sender, use a shared autocomplete experience, and inject referenced resources into the AI context rather than expanding into raw text.

---

| Option | Description | Selected |
|--------|-------------|----------|
| Styled chips inline in Sender | Colored chips, type-specific, atomic objects | ✓ |
| Plain text @references | Styled text only, no chip rendering | |

**User's choice:** Styled inline chips with type-specific icon and color. Chips behave as atomic objects (backspace removes whole chip).

---

| Option | Description | Selected |
|--------|-------------|----------|
| Unified popover | One popover mixing all types | ✓ |
| Type-filtered | @type: triggers per-type filtering | |

**User's choice:** Unified autocomplete popover. Typing @ opens one popover with all types mixed. Type icons distinguish them.

---

| Option | Description | Selected |
|--------|-------------|----------|
| Structured references | ReferenceToken[] in ContextOptimizerInput | ✓ |
| Resolved content at send | Expand into user message text | |

**User's choice:** Structured ReferenceToken[] passed into ContextOptimizerInput. ContextOptimizer resolves and decides budget allocation.

---

| Option | Description | Selected |

**User's choice:** Minimal ReferenceToken model. Token is a stable pointer — ContextOptimizer does resolution.

---

**User's choice:** Stale chip stays visible but greyed out. ContextOptimizer silently skips unresolvable refs at send time.

---

**User's choice:** Factory + registry pattern. ReferenceType enum + ReferenceResolver interface. Each type registers its own resolver.
