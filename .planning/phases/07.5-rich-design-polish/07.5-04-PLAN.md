    **Step A — Create `TLDRToggle.tsx` (D-17, D-18):**
    Pure presentational component. Props: `content: string`, `streaming?: boolean` (D-17: hard 500-char threshold, configurable via `TLDR_THRESHOLD` constant).
    - **CRITICAL guard per Pitfall 5:** Only render toggle when `!streaming && charCount > TLDR_THRESHOLD`. If streaming or below threshold, return children unchanged (pass-through).
    - Collapsed state: extract first 1-2 sentences via regex `/[.!?]+[\s\n]/` (split on sentence boundaries). Show preview text (~150-250 chars) + antd `Button` (link type) "Show More". Per D-18: no AI summarization, deterministic extraction only.
    - Expanded state: full content + "Show Less" button.
    - Use antd `Typography.Paragraph` with `ellipsis` as fallback; primary UX is explicit expand/collapse toggle.
    - Wrap Bubble content: `<TLDRToggle content={message.content} streaming={item.streaming}>{children}</TLDRToggle>`

    **Step B — Create `ChecklistCardGroup.tsx` (D-19, D-20):**
    XMarkdown `components.ol` renderer. Props: standard React `ol` element props (`children`, `start`).
    - Detection heuristic: ordered list with 2+ `<li>` children → render as checklist. Single item or non-list → fallback to default `<ol>` rendering.
    - Each checklist item: antd `Checkbox` + text. Checked state tracked in `useState` keyed by `messageId` (received via context or prop). Per D-20: session-only state, resets on reload.
    - Progress bar: antd `Progress` (line type, `percent={completed/total * 100}`) + text "{completed}/{total} completed". When all checked: "All {total} completed".
    - Checked items: line-through + 60% opacity per UI-SPEC.
    - **Pitfall 4 mitigation:** Wrap component in `React.memo` to maintain stable identity during XMarkdown streaming. The component MUST use module-level definition pattern (exported as named export, wrapped in `memo`).

    **Step C — Tests:**
    - TLDRToggle: verify hidden when streaming=true, shown when streaming=false and chars>500, char count near threshold edge cases (exactly 500, 501), sentence extraction correctness
    - ChecklistCardGroup: renders checkboxes for 2+ item lists, toggles check state, progress bar updates, "All completed" state, fallback rendering for single-item lists, memo stability
