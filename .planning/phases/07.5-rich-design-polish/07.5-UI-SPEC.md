## Color

All colors derive from the existing antd theme with `colorPrimary: #e0582e`. The built-in 60/30/10 split is managed by antd's design token algorithm (light/dark).

| Role | Token | Usage |
|------|-------|-------|
| Dominant (60%) | `colorBgContainer` | Page backgrounds, persona editor cards, memory browser cards, checklist cards |
| Secondary (30%) | `colorBgElevated` | Autocomplete popover, mention chip backgrounds, tip banner, stage indicator pills |
| Accent (10%) | `colorPrimary` (#e0582e) | Primary buttons (Save, Confirm), active Segmented option, voice recording indicator pulse, checklist checkmark color, progress bar fill |
| Text Primary | `colorText` | Body text, headings, labels |
| Text Secondary | `colorTextSecondary` | Descriptions, helper text, timestamp text |
| Text Tertiary | `colorTextTertiary` | Placeholder text, disabled chip text |
| Border | `colorBorderSecondary` | Card borders, chip borders, input borders, table borders |

**Accent (#e0582e) reserved for:**
- Voice recording indicator (pulsing dot + border)
- Active Segmented/Radiogroup selection
- Checklist checkbox checked state + progress bar fill
- "Confirm" / "Save" / "Got it" primary action buttons
- Tip banner accent border-left
- "Balanced" brevity option badge (default indicator)
- Memory fact confidence indicator (🟢 High >0.7)
- Autocomplete selected item highlight

**Second semantic colors:**
- `colorSuccess` (green): Saved conversation confirmation, "Balanced" active state
- `colorWarning` (orange/amber): 🟡 Medium confidence (0.4–0.7), stale reference chip border, "Still working..." stage indicator
- `colorError` (red): 🔴 Low confidence (<0.4), recording error state, destructive delete confirmation
- `colorInfo` (#e0582e): Informational tip banner, voice input supported indicator

**Confidence color indicators (Memory Browser):**
| Level | Threshold | Indicator | Token |
|-------|-----------|-----------|-------|
| High | > 0.7 | 🟢 Green dot | `colorSuccess` |
| Medium | 0.4–0.7 | 🟡 Amber dot | `colorWarning` |
| Low | < 0.4 | 🔴 Red dot | `colorError` |

**Mention chip type colors (inline in Sender):**
| Type | Icon | Color accent |
|------|------|-------------|
| @note | `FileTextOutlined` | `colorPrimary` tinted bg (10% opacity) |
| @tab | `PushpinOutlined` | `colorInfo` tinted bg (10% opacity) |
| @prompt | `MessageOutlined` | `colorSuccess` tinted bg (10% opacity) |

**Source:** `src/core/theme/antdConfig.ts` primary color `#e0582e`, antd algorithm-derived tokens

### Interaction Patterns

| Pattern | Implementation | Reference |
|---------|---------------|-----------|
| @mention autocomplete | Type `@` in Sender → popover with mixed-type results → select inserts chip | Adapt from WikilinkAutocomplete.tsx (203 lines) |
| Voice toggle | Tap mic button → start recording → interim text shows grey → tap again → final text at cursor | Web Speech API, CONTEXT.md D-13–D-16 |
| TL;DR collapse | Response completes → char count > 500 → show first 1–2 sentences + "Show More" button → expand to full | CONTEXT.md D-17, D-18 |
| Checklist interaction | Ordered list in AI response → renders as ChecklistCardGroup → tap checkbox to toggle → shows progress counter → state resets on reload | CONTEXT.md D-19, D-20 |
| Tip dismissal | Tip banner appears → user clicks "Got it" → stored in `np_edu_tips` → never shown again for that tip | CONTEXT.md D-21, D-22 |
| Save conversation | Click "Save as Note" → auto-creates note → opens NoteEditor pre-filled → bidirectional link | CONTEXT.md D-25–D-27 |

| State | Handling | Source |
|-------|----------|--------|
| Empty chat (no conversations) | Existing WelcomeCards + personalized greeting (from Phase 7.3/7.4) | CONTEXT.md |
| No notes for @note autocomplete | Dropdown shows "No notes found" empty state | Default |
| No pinned tabs for @tab autocomplete | Dropdown shows "No pinned tabs" empty state | Default |
| Voice input unsupported browser | Mic button hidden entirely | CONTEXT.md D-14 |
| Voice input error | Console error, recording stops, no visual toast | RESEARCH.md Pitfall 1 |
| Stale @mention reference | Chip renders disabled/grey, ContextOptimizer skips silently | CONTEXT.md D-06 |
| TL;DR during streaming | Toggle hidden until `hasNextChunk === false` | RESEARCH.md Pitfall 5 |

| Save conversation, <3 exchanges | Save button hidden | CONTEXT.md D-25 |
| PromptStarterUsageStore quota | Lightweight counters (<1KB total), no quota risk | RESEARCH.md Pitfall 6 |
