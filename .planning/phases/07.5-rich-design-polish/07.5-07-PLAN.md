<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User input → Sender textarea | plain text + @type:title syntax — textarea auto-escapes; no HTML injection |
| AI response → XMarkdown | Markdown rendered via XMarkdown + custom components — React auto-escapes children |
| Conversation content → MemoryDB (feedback persistence) | Feedback is `{ helpful: boolean, conversationId, timestamp }` — no user-generated content stored |
| Conversation content → NotesDB (save-to-note) | Full conversation transcript stored as note — same trust model as existing notes system |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07.5-14 | Information Disclosure | SaveToNoteFromChat export | low | accept | Export downloads to user's machine via Blob URL — same security model as any file download; user controls destination |
| T-07.5-15 | Denial of Service | ChatPage MARKDOWN_COMPONENTS | low | accept | Module-level constant — stable reference, no re-creation; zero performance risk |
| T-07.5-16 | Tampering | ConversationClosure feedback data | low | accept | Feedback is anonymous boolean + timestamp + conversationId; no PII; stored locally in IndexedDB |
</threat_model>
