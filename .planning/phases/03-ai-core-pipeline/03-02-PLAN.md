    - `createAnthropicAdapter(apiKey: string): ProviderAdapter`
    - Uses `createAnthropic` from `@ai-sdk/anthropic` (import: `import { createAnthropic } from '@ai-sdk/anthropic'`)
    - `createLanguageModel(modelId)` returns `anthropic(modelId)`
    - `supportsStructuredOutput = true`
    - `validateConnection()`: fetch `https://api.anthropic.com/v1/messages` with `x-api-key: {apiKey}` and `anthropic-version: 2023-06-01` header and a minimal message body `{ model: 'claude-haiku-4-latest', max_tokens: 1, messages: [{ role: 'user', content: 'ping' }] }`. If response is 200 or 4xx auth error (not 5xx), parse model list from response headers or return `{ ok: true, models: [] }` (Anthropic API does not expose a /models endpoint — list curated defaults instead). If network error or 5xx, return `{ ok: false, models: [] }`.
    - `getDefaultModelForTier(tier)` maps: FAST→'claude-haiku-4-latest', BALANCED→'claude-sonnet-4-latest', ADVANCED→'claude-opus-4-latest'
    - `getCacheStrategy()` returns 'anthropic-ephemeral' — Anthropic supports ephemeral cache control via `providerOptions.anthropic.cacheControl` per RESEARCH.md example
    - `getTelemetryMetadata()` returns `{ provider: 'anthropic' }`

    **2. src/core/ai/providers/gemini.ts** — Google Gemini adapter:
    - `createGeminiAdapter(apiKey: string): ProviderAdapter`
    - Uses `createGoogle` from `@ai-sdk/google` (import: `import { createGoogle } from '@ai-sdk/google'`)
    - `createLanguageModel(modelId)` returns `google(modelId)`
    - `supportsStructuredOutput = true`
    - `validateConnection()`: fetch `https://generativelanguage.googleapis.com/v1beta/models?key={apiKey}`. Parse `data.models[].name` (strip `models/` prefix). Return `{ ok: true, models }` on success. Return `{ ok: false, models: [] }` on network/5xx/permission error.
    - `getDefaultModelForTier(tier)` maps: FAST→'gemini-2.0-flash-lite', BALANCED→'gemini-2.0-flash', ADVANCED→'gemini-2.5-pro'
    - `getCacheStrategy()` returns 'prefix-only' (Gemini cachedContent API requires separate setup; not used in v0.1)
    - `getTelemetryMetadata()` returns `{ provider: 'gemini' }`

    **3. src/core/ai/providers/ollama.ts** — Ollama local model adapter:
    - `createOllamaAdapter(baseURL?: string): ProviderAdapter` — no API key needed (Ollama is local)
    - Uses `ollama` from `ollama-ai-provider` with optional baseURL (default `http://localhost:11434/api`)
    - `createLanguageModel(modelId)` returns `ollama(modelId)` — this uses ollama-ai-provider which handles the OpenAI-compatible API internally
    - `supportsStructuredOutput = false` — Ollama's structured output support depends on the loaded model (not guaranteed). Per D-04: flag as false so PlannerService automatically uses the fallback path.
    - `validateConnection()`: fetch `{baseURL}/api/tags`. Parse response `models[].name`. Return `{ ok: true, models }` on success. If fetch fails (connection refused), return `{ ok: false, models: [] }` — Ollama may not be running.
    - `getDefaultModelForTier(tier)` maps: FAST→'llama3.2:3b', BALANCED→'llama3.2', ADVANCED→'llama3.2:70b'
    - `getCacheStrategy()` returns 'prefix-only' (Ollama does not support native prompt caching)
    - `getTelemetryMetadata()` returns `{ provider: 'ollama', baseURL }`

    **Implementation rules:**
    - Each adapter file exports exactly one factory function (`createXxxAdapter`).
    - No default exports — use named exports only (established codebase convention).
    - Do NOT import from React, antd, or any UI library.
    - Do NOT call `useApiKeyStore()` — adapters receive API keys as parameters. ProviderRouter handles key retrieval.
    - Connection validation methods must NOT throw — always return `{ ok: boolean, models: string[] }`.
    - Per RESEARCH.md Don't Hand-Roll: use `fetch()` for connection validation only (the adapters delegate all AI generation to AI SDK via `createLanguageModel()`).
