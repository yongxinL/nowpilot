    **`streamToAsyncIterable(options: StreamAdapterOptions): AsyncIterable<StreamEvent>`:**
    
    Uses an `AsyncGenerator` that wraps AI SDK's `streamText` callbacks (`onChunk`, `onFinish`, `onError`).

    ```typescript
    import { StreamEvent } from '../types';
    import { PipelineError } from '../PipelineError';
    import type { LanguageModel } from 'ai';

    interface StreamAdapterOptions {
      model: LanguageModel;
      messages: Array<{ role: 'system' | 'user' | 'assistant'; content: string }>;
      tools?: Record<string, any>; // AI SDK tool definitions
      abortSignal?: AbortSignal;
    }

    async function* streamToAsyncIterable(options: StreamAdapterOptions): AsyncIterable<StreamEvent> {
      // Create a push queue — events are pushed by AI SDK callbacks, pulled by the async iterator
      const eventQueue: StreamEvent[] = [];
      let resolveNext: ((value: IteratorResult<StreamEvent>) => void) | null = null;
      let streamDone = false;
      let streamError: PipelineError | null = null;

      // Push helper
      const push = (event: StreamEvent) => { /* ... push to queue, resolve waiting consumer */ };

      // Start streamText (non-blocking)
      const streamPromise = streamText({
        model: options.model,
        messages: options.messages,
        tools: options.tools,
        abortSignal: options.abortSignal,
        onChunk({ chunk }) {
          if (chunk.type === 'text-delta') {
            push({ type: 'text-delta', content: chunk.textDelta });
          } else if (chunk.type === 'tool-call') {
            push({ type: 'tool-call', toolName: chunk.toolName, input: chunk.args });
          } else if (chunk.type === 'tool-result') {
            push({ type: 'tool-result', toolName: chunk.toolName, output: chunk.result });
          }
        },
        onFinish({ usage }) {
          push({
            type: 'done',
            usage: usage ? { promptTokens: usage.promptTokens, completionTokens: usage.completionTokens } : undefined,
          });
        },
        onError({ error }) {
          // do NOT push error event — capture for final yield
        },
      });

      // Yield events from the queue until done
      try {
        while (true) {
          // Wait for either a queued event or stream completion
          const event = await nextEvent();
          yield event;
          if (event.type === 'done' || event.type === 'error') break;
        }
      } finally {
        await streamPromise; // ensure cleanup
      }
    }
    ```

    **Implementation notes:**
    - Use an async generator function (`async function*`) returning `AsyncIterable<StreamEvent>`.
    - The internal queue pattern: AI SDK callbacks push events to a queue; the generator pulls from the queue and yields.
    - Imports: `streamText` from 'ai', types from '../types', PipelineError from '../PipelineError'.
    - Do NOT import React, DOM APIs (requestAnimationFrame), or UI libraries — this is pipeline-layer only per D-13.
    - Error events: wrap the raw error in `PipelineError('UNKNOWN', error.message)`.
    - Abort: if `abortSignal` is already aborted before starting, yield a single `done` event immediately.

    **1. StageLabel state machine (per UI-SPEC streaming contract):**
    ```typescript
    export type StageLabel = 'idle' | 'reading-page' | 'planning' | 'generating' | 'done';

    export const STAGE_LABELS: Record<StageLabel, string> = {
      'idle': '',
      'reading-page': 'Reading page context…',
      'planning': 'Planning response…',
      'generating': 'Generating…',
      'done': '',
    };

    const VALID_TRANSITIONS: Record<StageLabel, StageLabel[]> = {
      'idle': ['reading-page', 'planning'],
      'reading-page': ['planning', 'done'],
      'planning': ['generating', 'done'],
      'generating': ['done'],
      'done': [],
    };
    ```

    **2. ChunkBuffer class:**
    - `private buffer: string = ''`
    - `private stage: StageLabel = 'idle'`
    - `private tokenCount: number = 0`
    - `private rAFId: number | null = null`
    - `private onFlush: ((text: string) => void) | null = null`

    Methods:
    - `write(text: string): void` — appends to buffer, schedules rAF flush if not already scheduled.
    - `flush(): string` — cancels pending rAF, returns accumulated text, clears buffer. Calls `onFlush` if set.
    - `transition(stage: StageLabel): void` — validates transition against `VALID_TRANSITIONS`. If invalid (e.g., trying to go back from 'generating' to 'reading-page'), logs a warning and does NOT transition. If valid, updates stage.
    - `getStage(): StageLabel` — returns current stage.
    - `getStageLabel(): string` — returns the human-readable label from `STAGE_LABELS[stage]`.
    - `addTokens(prompt: number, completion: number): void` — increments token count.
    - `getTokenCount(): number` — returns cumulative token count.
    - `reset(): void` — clears buffer, resets stage to idle, cancels pending rAF.
    - `setOnFlush(callback: ((text: string) => void) | null): void` — sets the flush callback (for Phase 7 UI integration).
    - `destroy(): void` — cancels pending rAF, clears state. Call when component unmounts.

    **3. rAF batching:**
    - On `write()`, if `rAFId` is null, schedule `rAFId = requestAnimationFrame(() => { const text = this.flush(); if (text && this.onFlush) this.onFlush(text); })`.
    - On `flush()`, if `rAFId` is not null, `cancelAnimationFrame(rAFId)` and set to null.
    - The consumer (Phase 7 Chat UI) calls `write()` for each text-delta event and receives batched text via the `onFlush` callback or by polling `flush()`.
