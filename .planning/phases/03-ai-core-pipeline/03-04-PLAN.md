    Create `src/core/ai/StructuredOutput.ts` — a pure-function module implementing a one-shot JSON repair strategy per D-03 and RESEARCH.md Appendix L. No class, no state — just exported functions.

    **`repairJSON<T>(rawText: string, schema: z.ZodSchema<T>): T`:**
    1. Trim input. If empty → throw `PipelineError('SCHEMA_INVALID', ...)`.
    2. Strip markdown code fences: remove leading ` ```json ` / ` ``` ` and trailing ` ``` `.
    3. Extract JSON block: find the first `{` or `[` and the matching closing character. If none found → SchemaError.
    4. Apply fixes (one-shot, single pass per fix type):
       - Remove trailing commas before `}` or `]` (regex: `,(\s*[}\]])` → `$1`).
       - Complete truncated JSON: if `{` count > `}` count, append missing `}` characters. Same for `[` and `]`.
       - If a string value is unterminated (odd number of unescaped quotes), append a closing quote.
    5. Parse the repaired string with `JSON.parse()`. If parse fails → SchemaError.
    6. Validate parsed object against the provided Zod schema. If validation fails → SchemaError. If passes → return typed result.

    **`generateWithRepair<T>(adapter: ProviderAdapter, tier: ModelTier, prompt: string, schema: z.ZodSchema<T>, abortSignal?: AbortSignal): Promise<T>`:**
    - Calls `generateText` (from 'ai') with the adapter's language model and JSON-instructed system prompt.
    - Passes the raw text output to `repairJSON(text, schema)`.
    - On success: return typed result.
    - On SchemaError: throw `PipelineError('SCHEMA_INVALID', 'The AI returned an unexpected response format. Please try again.', { rawText: rawText.slice(0, 500) })`.
    - This is one-shot — no retry loop. Per D-03: one failed repair is terminal.

Tests should exercise each repair path (fences, commas, truncation) independently, then combinatorially.

    Define using `z.discriminatedUnion('action', [...])`. Per RESEARCH.md Pitfall 2: use v4 APIs exclusively.

    ```typescript
    import { z } from 'zod/v4'; // or just 'zod' if v4 is top-level

    const AnswerSchema = z.strictObject({
      action: z.literal('answer'),
      reasonCode: z.string().max(64),
    });

    const RunToolSchema = z.strictObject({
      action: z.literal('run_tool'),
      toolName: z.string().max(64),
      input: z.record(z.string(), z.unknown()),
    });

    const AskClarificationSchema = z.strictObject({
      action: z.literal('ask_clarification'),
      question: z.string().max(200),
    });

    export const PlannerDecisionSchema = z.discriminatedUnion('action', [
      AnswerSchema,
      RunToolSchema,
      AskClarificationSchema,
    ]);

    export type PlannerDecision = z.infer<typeof PlannerDecisionSchema>;
    ```
