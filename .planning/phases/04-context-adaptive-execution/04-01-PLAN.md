Create `src/core/context/contextTypes.ts` with the following exports, following the Zod schema + z.infer pattern from providerTypes.ts:

1. **ModelContextTier type** (string union: `'tiny' | 'small' | 'medium' | 'large'`). No Zod schema needed — it's a value type, not validated input.

2. **PromptSectionKind** — `z.enum([...])` covering all section types per D-14 canonical ordering: `'system_prompt'`, `'task_instructions'`, `'workspace_context'`, `'memory'`, `'tool_schemas'`, `'page_context'`, `'conversation_history'`, `'user_input'`, `'tool_results'`, `'notes_metadata'`, `'debug_data'`, `'preferences'`. Export both the schema and inferred type.

3. **PromptSection interface** — `{ kind: PromptSectionKindType; sourceId: string; content: string; priority?: number }`. The `priority` field is optional and defaults to the position in CONTEXT_SOURCE_PRIORITY (D-09).

4. **SectionProvenanceOutcome** — `z.enum(['kept', 'truncated', 'compressed', 'dropped'])`. Export both schema and type.

5. **CompressionMethod** — `z.enum(['summarise', 'structural', 'topk'])`. Optional field on provenance entries.

6. **DegradationReason** — `z.enum(['budget', 'minimal_mode', 'degradation_step_1', 'degradation_step_2', 'degradation_step_3', 'degradation_step_4', 'degradation_step_5', 'degradation_step_6', 'degradation_step_7'])`.

7. **SectionProvenanceEntry interface** per D-10: `{ kind: PromptSectionKindType; sourceId: string; originalTokens: number; finalTokens: number; outcome: SectionProvenanceOutcomeType; compressionMethod?: CompressionMethodType; reason?: DegradationReasonType }`.

8. **ContextProvenanceManifest interface**: `{ operationId: string; tier: ModelContextTier; inputBudget: number; outputBudget: number; safetyMargin: number; sections: SectionProvenanceEntry[]; degradationSteps: DegradationReasonType[]; minimalMode: boolean; createdAt: number }`.

9. **ContextOptimizerInput interface**: `{ operationId: string; providerId: string; modelId: string; modelContextWindow: number; userInput: string; systemPrompt: string; taskInstructions?: string; workspaceContext?: string; pageContext?: string; toolSchemas?: Array<{ name: string; schema: unknown }>; selectedToolSchemas?: Array<{ name: string; schema: unknown }>; memory?: Array<{ id: string; content: string; score: number }>; preferences?: Record<string, unknown>; conversationHistory?: Array<{ role: string; content: string }>; notes?: Array<{ id: string; content: string }>; debugData?: Record<string, unknown> }`. Mark optional fields with `?`.

10. **OptimizedContext interface**: `{ operationId: string; tier: ModelContextTier; inputBudget: number; outputBudget: number; safetyMargin: number; sections: PromptSection[]; provenance: ContextProvenanceManifest; minimalMode: boolean }`.

11. **ContextTooLargeError class** per RESEARCH.md lines 254-269: Extends Error with `code: 'CONTEXT_TOO_LARGE'`, `estimatedTokens: number`, `budget: number`. Constructor takes both numbers. `this.name = 'ContextTooLargeError'`. Error message: `"Context size (${estimatedTokens} tokens) exceeds available budget (${budget} tokens) after all degradation steps"`. No sensitive data (modelId, providerId, raw content) in the message.

12. **contextOptimizerInputSchema** — Zod schema validating ContextOptimizerInput. `modelContextWindow`: positive integer. `userInput`: non-empty string (ASVS V5). `operationId`: non-empty string. All optional fields remain optional in schema.

Export all interfaces as types (not values). Export only Zod schemas and the error class as runtime values.

    - Test `contextOptimizerInputSchema.parse()` succeeds with valid input; rejects with ZodError on missing `userInput`, negative `modelContextWindow`, or missing `operationId`.
    - Test `SectionProvenanceOutcome` and `DegradationReason` enum validation via Zod parse.

Create `src/core/context/ContextProvenanceManifest.ts` with manifest builder and helper functions per D-10:

1. **Re-export** relevant types from contextTypes.ts (SectionProvenanceEntry, ContextProvenanceManifest, SectionProvenanceOutcome, DegradationReason) so consumers import from one place.

2. **createManifest(params: {...}): ContextProvenanceManifest** — Builder function:
   - Takes: `operationId`, `tier`, `inputBudget`, `outputBudget`, `safetyMargin`.
   - Returns a manifest with empty `sections[]`, empty `degradationSteps[]`, `minimalMode: false`, `createdAt: Date.now()`.
   - The caller (ContextOptimizer) populates sections and degradationSteps during optimization.

3. **recordSection(manifest, entry: SectionProvenanceEntry): ContextProvenanceManifest** — Returns new manifest with the section appended to `sections[]`. Immutable — doesn't mutate input.

4. **recordDegradationStep(manifest, step: DegradationReasonType): ContextProvenanceManifest** — Appends step to `degradationSteps[]`. Immutable.

5. **setMinimalMode(manifest): ContextProvenanceManifest** — Returns manifest with `minimalMode: true`. Immutable.

6. **createSectionEntry(params: {...}): SectionProvenanceEntry** — Factory for creating provenance entries:
   - Takes: `kind`, `sourceId`, `originalTokens`, `finalTokens`, `outcome`, optional `compressionMethod`, optional `reason`.
   - `finalTokens` defaults to 0 when outcome is `'dropped'`.
   - Records both retained AND dropped sections per D-10 (dropped sections have `outcome: 'dropped'`, `finalTokens: 0`).

7. **Zod schema** — `contextProvenanceManifestSchema` validating the full manifest structure. Use `z.object()` with all fields from the interface.

Follow the discriminated union pattern from pipelineTypes.ts for the `outcome` field — each outcome variant has type-specific optional fields.

8. **Create `tests/core/context/ContextProvenanceManifest.test.ts`** — using Vitest:
    - Test `createManifest()` returns manifest with empty sections, empty degradationSteps, minimalMode: false, createdAt is a timestamp.
    - Test `recordSection()` appends entry without mutating original manifest (immutability).
    - Test `createSectionEntry()` with outcome:'dropped' has finalTokens: 0; outcome:'kept' preserves finalTokens === originalTokens.
    - Test `createSectionEntry()` with outcome:'compressed' requires compressionMethod field.
    - Test `recordDegradationStep()` and `setMinimalMode()` work immutably.
    - Test `contextProvenanceManifestSchema.parse(validManifest)` succeeds; rejects malformed manifests.
