    Add `compactConversation(conversationId:string, providerAdapter:ProviderAdapter):Promise<{success:boolean, error?:string, code?:string, summaryId?:string}>`:
    1. Get all messages for this conversation from memory_messages store (ordered by seq).
    2. Extract middle messages: messages between index 2 (after head) and last N messages (tail). Head = first 2 messages. Tail = last 2 for tiny, 4 for small, 6 for medium/large. Middle = everything else.
    3. Format messages into prompt text: "User: {content}\nAssistant: {content}\n..." for each message in middle range.
    4. Build summary prompt per RESEARCH pattern:
       ```
       Summarize the following conversation excerpt in 2-3 concise sentences.
       Capture only: decisions made, goals set, user preferences stated, facts mentioned, and open tasks.
       Do NOT summarize conversational filler, greetings, or small talk.
       
       Conversation:
       {formattedMessages}
       
       Summary:
       ```
    5. Call provider adapter's language model: `providerAdapter.createLanguageModel(modelId).doGenerate({prompt, maxTokens:200, temperature:0.3})`. Model ID = cheapest available (use ProviderRouter.getCompressionModel() or accept a modelId string parameter). Use `generateText` from the AI SDK if available, otherwise the adapter's native call.
    6. If response is empty/whitespace: return {success:false, code:'EMPTY_SUMMARY'} — messages preserved.
    7. If provider throws: return {success:false, code:'PROVIDER_ERROR', error:error.message} — messages preserved.
    8. If response is valid: trim to 500 chars max, store as ConversationSummary with unique id, conversationId, summary text, messageRange {start:headEndIndex, end:tailStartIndex}, createdAt:Date.now().
    9. Store via saveSummary().
    10. Return {success:true, summaryId}.
    11. NEVER delete original messages (D-10: "Original messages preserved — never permanently deleted during compaction").

    **A. src/core/ai/AgentTurnInput.ts — add memory-preload helper:**

    Do NOT modify the existing `createAgentTurnInput` factory (it takes a Partial and fills defaults). Instead, add a new exported async function:

    ```typescript
    export async function createAgentTurnInputWithMemory(
      partial: Partial<AgentTurnInput>,
      conversationId: string,
      tier: string,
    ): Promise<AgentTurnInput> {
      const memoryEngine = getMemoryEngine();
      const base = createAgentTurnInput(partial);
      // Populate memory context
      const retrievalResult = await memoryEngine.retrieve({
        conversationId,
        query: partial.userInput ?? '',
        tier: tier as RetrievalOptions['tier'],
      });
      if (retrievalResult.success) {
        base.memoryHints = retrievalResult.items;
      }
      // Populate preferences
      const prefs = await memoryEngine.getPreferences();
      base.preferences = prefs;
      // Populate persona behavior
      const persona = await memoryEngine.getPersona();
      if (persona) {
        base.personaBehavior = persona as AgentTurnInput['personaBehavior'];
      }
      return base;
    }
    ```

    Export `createAgentTurnInputWithMemory`. The existing `createAgentTurnInput` remains unchanged for backward compatibility. Callers that need memory context use the new factory.
