<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| markdown content → LinkParser regex | Untrusted user-authored markdown enters regex; regex is read-only extraction, no eval/code execution |
| Note content → MiniSearch index | Text content enters MiniSearch for indexing; MiniSearch does not execute scripts — text stored as plain tokens |
| Note content → cosine similarity | User-authored text tokenized for bag-of-words; no HTML/script execution path |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-01 | Tampering | LinkParser regex | low | accept | Regex captures text only between `[[` and `]]` — no eval, no dynamic code execution. Parsed titles are trim()+sanitized. Worst case: malformed wikilink produces garbage title that becomes unresolved. |
| T-05-02 | Tampering | NotesDB.save() — note content injection | medium | mitigate | Note content is user-owned markdown. Rendered downstream via PortableMarkdown (Phase 1) which uses DOMPurify. No raw HTML execution path in the notes layer. Schema validates at Zod boundary. |
| T-05-03 | Information Disclosure | MiniSearchNoteIndex — JSON persistence | low | accept | Index stored as plain JSON in IndexedDB. Contains tokenized text content (public to the user's own browser). Chrome extension storage is sandboxed per-extension. |
| T-05-04 | Denial of Service | NoteGraph.computeSimilarity — N^2 computation | low | accept | Similarity computed on-demand for getRelatedNotes, not eagerly. Capped at top-10 results. For <5000 notes, O(N) per query is acceptable. Phases 5a/7 may add caching if needed. |
| T-05-SC | Tampering | npm installs (minisearch, idb, zustand, zod) | high | mitigate | All packages verified via Package Legitimacy Audit (RESEARCH.md) — npm registry, age, download count, source repo. No new packages needed in Phase 5. All already installed with [ASSUMED] verdict. |
</threat_model>
