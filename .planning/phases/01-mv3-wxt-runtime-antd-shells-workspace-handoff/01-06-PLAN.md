## Task 01-06-01 — `WorkspaceRouter.openStandalone` + tab dedup + `hydrateFromURL` fix
**Requirements:** REQ-F05 · drivers **D-04, D-07** · **Threat ref:** T-01-16 · **`autonomous`: true**

- **H2 decision (locked):** `hydrateFromURL(searchParams: URLSearchParams)` stays in `WorkspaceRouter.ts`; it calls the new `WorkspaceStore.setWorkspaceId(id)` (through `set()`). All plan references to hydrateFromURL use WorkspaceRouter.hydrateFromURL (H2).

### Files

- **Modify:** `src/core/workspace/WorkspaceStore.ts` (add `setWorkspaceId`; rename tab-id field)

### Ordered implementation steps
1. **Re-grep (VAI-08):** find `openFullApp`, `app.html`, `openedFullAppTabId`, `setOpenedFullAppTabId`, `Object.assign(store` in `WorkspaceRouter.ts`/`WorkspaceStore.ts`.
2. In `WorkspaceStore.ts`: add `setWorkspaceId(id)` as a `set(state => ({ state: { ...state.state, workspaceId: id } }))` action; rename `openedFullAppTabId → openedStandaloneTabId` and `setOpenedFullAppTabId → setOpenedStandaloneTabId` at every declaration + call site.
3. In `WorkspaceRouter.ts`: rename `openFullApp → openStandalone`; change the target from `getURL('app.html')` to `getURL('standalone.html')`.
4. **Tab dedup (T-01-16):** `chrome.tabs.query({ url: chrome.runtime.getURL('standalone.html*') }, tabs => { ... })`:
   - if an existing tab is found → `chrome.tabs.update(tab.id, { active: true })` and `chrome.windows.update(tab.windowId, { focused: true })` (cross-window focus); call `opts?.onSettled?.({ ok:true })` in the update callback.
   - else → `chrome.tabs.create({ url: standaloneUrlWithParams })`; call `onSettled({ ok:true })` in the create callback.
   - On `chrome.runtime.lastError` in any callback → `onSettled({ ok:false, error: String(lastError.message) })`.
   - Build `standaloneUrlWithParams` = `standalone.html?workspaceId=…&conversationId=…&page=…` (omit absent params).
5. **`hydrateFromURL` fix (H2):** replace `Object.assign(store, { workspaceId })` with `WorkspaceStore.getState().setWorkspaceId(searchParams.get('workspaceId') ?? '')` and, if present, `setConversationId(searchParams.get('conversationId'))`. This ensures persistence + subscribers fire (the `Object.assign` path bypassed them).

### Edge / error behavior
- **Idempotent re-open (T-01-16):** second `openStandalone` for the same workspace focuses the existing tab (no duplicate), including when it lives in another window.
