<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| extension-page→chrome.storage.local | State read/write crosses from extension page context to browser-managed storage |
| sidepanel→app (BroadcastChannel) | Theme change messages cross between Side Panel and Full App Tab via same-origin BroadcastChannel |
| extension→browser (matchMedia) | Theme auto-mode reads OS preference via window.matchMedia |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Tampering | chrome.storage.local | medium | accept | Extension storage is sandboxed per-extension by Chrome — other extensions cannot access this extension's storage. Accept for ASVS L1. |
| T-01-02 | Information Disclosure | BroadcastChannel (np_theme) | low | accept | BroadcastChannel is same-origin scoped to chrome-extension://\<id\> — only this extension's pages can receive messages. No sensitive data in theme messages. |
| T-01-03 | Denial of Service | ThemeToggle (rapid clicks) | low | accept | Zustand immer middleware provides atomic state transitions; rapid cycling through 3 modes has no persistent side effects. Accept for shell-only phase. |
| T-01-04 | Elevation of Privilege | SidePanelShell | low | accept | No auth or permission escalation in Phase 1 shell. All actions (theme toggle, tab switch, open full app) are local UI state changes. |
</threat_model>
