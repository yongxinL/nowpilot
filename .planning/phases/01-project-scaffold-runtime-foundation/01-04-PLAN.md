## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| background-SW→chrome.storage.local | Onboarding flag write crosses from service worker to browser storage |
| chrome.storage.local→SidePanelShell | Onboarding flag read determines whether wizard renders |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-09 | Tampering | chrome.storage.local onboardingComplete | low | accept | The onboarding flag controls only whether a welcome wizard displays. Tampering it (setting to false after completion) would re-show onboarding — annoying but not security-sensitive. No auth or data access gates depend on this flag. |
| T-01-10 | Repudiation | OnboardingWizard (skipping) | low | accept | Skip and Complete both call the same onComplete callback. No audit trail needed for onboarding completion — it's a UX convenience, not a security event. |
</threat_model>
