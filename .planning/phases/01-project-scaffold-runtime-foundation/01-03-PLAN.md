    Create src/core/commands/CommandRegistry.ts with NO React imports (pure TypeScript, src/core/ rule per RESEARCH.md Anti-Pattern: "Core modules must remain framework-agnostic").

    Export type `Command`:
    ```typescript
    export interface Command {
      id: string;
      name: string;
      description: string;
      category: string;
      action: () => void;
    }
    ```

    Export `CommandRegistry` object with methods:
    - `register(cmd: Command): void` — adds to internal Map<string, Command>; throws Error on duplicate id
    - `unregister(id: string): void` — removes from Map; no-op if not found
    - `get(id: string): Command | undefined`
    - `getAll(): Command[]` — returns all commands as array
    - `search(query: string): Command[]` — filters commands where `cmd.name.toLowerCase().includes(query.toLowerCase()) || cmd.description.toLowerCase().includes(query.toLowerCase())`. Returns ALL commands when query is empty string. Returns empty array on no match.
    - `execute(id: string): void` — calls command.action(); throws Error if id not found

    Use simple `String.prototype.includes()` for fuzzy matching — per RESEARCH.md "Don't Hand-Roll" table: command set is <20 items in Phase 1, no full fuzzy search library needed.

    The `action` field stores a synchronous callback. Commands execute immediately — no async/Promise support needed in Phase 1 (all Phase 1 commands are synchronous: toggle theme, open full app, reload extension).

    Create tests/core/commands/CommandRegistry.test.ts: test all behaviors listed above. No React or DOM needed — pure unit tests.
  </action>

    ```typescript
    interface CommandPaletteProps {

      open: boolean;
      onClose: () => void;
    }
    ```
    Takes an array of `Command` objects from `CommandRegistry` (or a surface-filtered subset). The parent shell manages open/close state and passes its surface-specific commands.

    **Implementation per UI-SPEC "Command Palette (Modal overlay)" and RESEARCH.md Pattern 3:**

    - **Modal:** antd Modal, open={open}, footer={null}, closable, onCancel={onClose}, width={560}, centered. DestroyOnClose to reset state.
    - **Input:** antd Input, autoFocus, placeholder="Search commands…", value={query}, onChange updates query state and resets selectedIndex to 0. Use size="large".
    - **Results list:** antd List with dataSource={filtered}, renderItem shows a List.Item with:

      - Right: command category label (Typography.Text type="secondary", smaller)
      - Description below name as Typography.Text type="secondary" (subtle)
      - Selected item background: `colorPrimaryBg` token when index === selectedIndex

      - `ArrowDown`: selectedIndex = Math.min(selectedIndex + 1, filtered.length - 1)
      - `ArrowUp`: selectedIndex = Math.max(selectedIndex - 1, 0)
      - `Enter`: if filtered[selectedIndex] exists, execute action() and onClose()
      - The listener only fires when open===true (guard in useEffect dependencies)
