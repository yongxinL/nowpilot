## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| sidepanel→app (BroadcastChannel np_theme) | Theme change messages published from one surface, consumed by the other |
| app→chrome.storage.local | Theme mode persisted to browser-managed storage |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-05 | Spoofing | BroadcastChannel np_theme | medium | mitigate | ThemeSync hook validates message type === 'THEME_CHANGED' before acting. Non-matching messages are silently dropped. ThemeMode is a union type — invalid mode values (not 'light'|'dark'|'auto') are rejected by TypeScript and the immer setter. |
| T-01-06 | Information Disclosure | BroadcastChannel np_theme | low | accept | Channel carries only theme mode enum — no PII, no secrets, no workspace data. Same-origin scoping prevents other extensions from receiving messages. |
</threat_model>
