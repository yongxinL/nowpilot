## Trust Boundaries

|----------|-------------|
| AgentTurnInput → ContextOptimizer | Untrusted user input (userInput field) crosses into the optimization pipeline — must be validated and size-bounded |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-01 | Tampering | TokenBudget.estimateTokens() | low | mitigate | Non-negative integer guard: if text is empty, return 0. Input validation ensures text is a string before estimation. Malformed inputs (null/undefined) default to 0 tokens. |
