## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| npm registry → build | Two new packages enter the dependency graph and are bundled into the extension. |
| `wxt.config.ts` → generated manifest | The manifest is the extension's declared privilege surface; a silent addition is a privilege escalation (§16.4). |
