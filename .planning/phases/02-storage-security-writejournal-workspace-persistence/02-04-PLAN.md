<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Presentation surface → credential port | Components must never reach the vault; only an authorised consumer may call `retrieve`. |
| User input → port | A blank or malformed credential field must not create or overwrite a stored credential. |
| `chrome.storage.local` → vault | A stored install secret can be missing, truncated or tampered with; the reader must fail closed. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-18 | Elevation of Privilege | component → vault import | high | mitigate | The port takes the vault as a parameter (no vault import) and a source-level scan over `src/components/**` fails on any direct import; the scan is proved to have teeth by a temporary violation. |
| T-02-19 | Tampering | blank-credential overwrite | high | mitigate | `store`/`replace` reject empty, whitespace, non-string and over-long input before any vault call; the fake vault's call count is asserted to stay zero. |
| T-02-20 | Information Disclosure | port error surface | high | mitigate | Typed redacted codes only; the failure case asserts the vault's internal error never reaches the caller and no value reaches the log ring buffer. |
| T-02-21 | Tampering | install-secret race | medium | mitigate | Per-key serialised writes plus read-back verification; a concurrent-create case asserts one durable value. |
| T-02-22 | Denial of Service | malformed install secret | medium | mitigate | A malformed or wrong-length stored secret returns a typed failure and is never silently regenerated over a usable value. |
| T-02-SC | Tampering | npm installs | high | mitigate | No install in this plan. |
