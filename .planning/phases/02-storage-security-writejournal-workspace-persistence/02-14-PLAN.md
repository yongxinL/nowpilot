## Why the corrected gate is shaped this way (decisions taken at planning time)

- **Placement:** `tests/isolation/` rather than editing the Phase-1 fixture suite into a repo-wide gate. Both `verify:phase-1` and `verify:phase-2` already enumerate `tests/isolation` as a directory, so one file becomes the cross-phase instrument with zero gate-script churn. It also matches the established isolation-gate idiom (`background-no-indexeddb.test.ts`): pure exported predicate, in-memory self-tests, real-graph assertion, read-only by construction.
- **Comment stripping is mandatory, not optional.** `stripComments` is already the repository's source-scan idiom (`tests/isolation/banned-imports.test.ts`, `tests/isolation/background-no-indexeddb.test.ts`) and its absence is the single defect that produced Gap 1.
- **Import-resolution, not string matching.** The gate resolves every module specifier (relative, `@/`, `~/`) and computes a transitive taint set (the three boundary modules plus every module that re-exports one). A name check alone would be evaded by `import { X } from '../../services'`.
- **Exact-path allowlist, never a directory.** The only approved vault import in `src/` is the edge `src/core/security/KeyVault.ts → src/core/security/EncryptedStorage.ts`. Nothing is approved to import `KeyVault` today, because Phase 2 deliberately has no production composition root (D2-01). Phase 3's composition root must add its edge here deliberately, in the commit that wires it — that is the gate's documented extension point, and it is the reason this plan records it in the SUMMARY.
- **`src/` only.** The gate never scans `tests/`, so Phase 2 tests may reference the port explicitly (they already do, in `tests/core/security/credentialStorePort.test.ts` and `tests/integration/onboardingTwoSurface.integration.test.ts`).
- **`02-VERIFICATION.md` is left byte-unchanged.** It is a truthful record of the state at 2026-09-24T14:40Z and re-verification owns it. The correction lives in `02-14-SUMMARY.md` and in `02-VALIDATION.md`'s sign-off.
