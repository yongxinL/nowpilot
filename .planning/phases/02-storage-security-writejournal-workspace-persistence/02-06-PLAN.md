  <action>
    Create `src/core/utils/RateLimiter.ts`. Pure utility — no dependencies on other project modules. No `debugLog` needed (not a source of errors — returns structured results per D-21).

    CONCRETE IMPLEMENTATION REQUIREMENTS:

    1. Export interface `RateLimiterConfig`:
       - `capacity: number` — max tokens (burst capacity)
       - `refillRate: number` — tokens per second

    2. Export interface `RateLimitResult`:
       - `allowed: boolean` — true if token was acquired
       - `remaining: number` — tokens remaining after this call (0 if not allowed)
       - `retryAfter: number` — milliseconds until next token available (0 if allowed)

    3. Export class `RateLimiter`:
       - `private tokens: number` — current token count, initialized to `config.capacity`
       - `private lastRefill: number` — timestamp of last refill in ms (`Date.now()`), initialized in constructor
       - `private readonly capacity: number`
       - `private readonly refillIntervalMs: number` — computed as `1000 / config.refillRate` in constructor

    4. Constructor `constructor(config: RateLimiterConfig)`:
       - Store `this.capacity = config.capacity`
       - Store `this.tokens = config.capacity`
       - Store `this.lastRefill = Date.now()`
       - Compute: `this.refillIntervalMs = 1000 / config.refillRate`

    5. Public method `tryAcquire(): RateLimitResult` — per D-21 (structured result, not exception):
       a. Call `this.refill()`.
       b. If `this.tokens >= 1`:
          - `this.tokens -= 1`
          - Return `{ allowed: true, remaining: Math.floor(this.tokens), retryAfter: 0 }`
       c. Else (tokens < 1):
          - Compute deficit: `const deficit = 1 - this.tokens`
          - Return `{ allowed: false, remaining: 0, retryAfter: Math.ceil(deficit * this.refillIntervalMs) }`

    6. Private method `refill(): void`:
       a. `const now = Date.now()`
       b. `const elapsed = now - this.lastRefill` (milliseconds since last refill)
       c. `const newTokens = elapsed / this.refillIntervalMs` (tokens earned in elapsed time)
       d. `this.tokens = Math.min(this.capacity, this.tokens + newTokens)` — per D-20, never exceed capacity
       e. `this.lastRefill = now`

    7. Run `npx tsc --noEmit` to verify compilation.
  </action>
