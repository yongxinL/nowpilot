<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Surface ↔ `chrome.storage.session` | Two documents race on one record with no atomic primitive; a lost race must be detectable. |
| Stale writer → `np_workspace` | A surface whose authority lapsed may still attempt a write. |
| Broadcast channel → other surface | A payload crosses a document boundary and may be forged or stale. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-30 | Tampering | lost CAS race | high | mitigate | Read-back verification turns an undetectable loss into a typed secondary outcome; the CAS-conflict case asserts the loser never overwrites the record. |
| T-02-31 | Tampering | stale writer | high | mitigate | `assertStillPrimary()` re-reads immediately before a write and rejects on a newer `electedAt`; the case drives a strictly newer epoch. |
| T-02-32 | Denial of Service | hung upgrade / stuck election | medium | mitigate | The election has no blocking wait: an unavailable storage area resolves the typed `STORAGE_UNAVAILABLE` error, and staleness is time-bounded. |
| T-02-33 | Information Disclosure | broadcast payload | medium | mitigate | The payload carries only two validated identifiers; a complete state object cannot be constructed through the exported API and is asserted absent. |
| T-02-34 | Repudiation | fabricated authority | high | mitigate | A surface reports primary only after a successful read-back; no optimistic promotion path exists and the mirror state is entered on every rejection. |
| T-02-35 | Tampering | non-monotonic workspace write | medium | mitigate | Version ordering is enforced before the write; the lower-version case asserts the stored value is unchanged. |
| T-02-SC | Tampering | npm installs | high | mitigate | No install in this plan. |
</threat_model>
