    - `notes_notes`: key `string`, value `{ id: string; title: string; content: string; created: number; updated: number; tags: string[] }`
    - `notes_concepts`: key `string`, value `{ slug: string; label: string; description: string; linkedNoteIds: string[] }`
    - `memory_messages`: key `[string, number]` (compound: conversationId + seq), value `{ conversationId: string; seq: number; role: string; content: string; timestamp: number }`
    - `memory_userFacts`: key `string`, value `{ id: string; fact: string; category: string; confidence: number; created: number; updated: number; source: string }`
    - `memory_summaries`: key `string`, value `{ conversationId: string; summary: string; messageCount: number; created: number; updated: number }`
    - `errors`: key `string`, value `{ id: string; timestamp: number; level: string; message: string; stack?: string; context?: unknown }`
    - `transaction_log_transactions`: key `string`, value `{ id: string; type: string; provider: string; model: string; startTime: number; endTime?: number; status: string; metadata?: unknown }`
    - `transaction_log_promptTraces`: key `string`, value `{ id: string; transactionId: string; tokens: number; cached: boolean; truncated: boolean }`
    - `transaction_log_toolTraces`: key `string`, value `{ id: string; transactionId: string; toolName: string; allowed: boolean; outcome: string; timestamp: number }`
    - `transaction_log_providerTraces`: key `string`, value `{ id: string; transactionId: string; provider: string; attempts: number; circuitBreakerOpen: boolean; timestamp: number }`
    - `write_journal_entries`: key `string`, value `{ id: string; operation: string; status: 'pending' | 'applying' | 'completed' | 'failed' | 'rolled-back'; createdAt: number; updatedAt: number; attempts: number; targetIds: Record<string, string>; steps: Array<{ name: string; status: 'pending' | 'completed' | 'failed'; error?: string }> }`, indexes `{ 'by-status': string }`

    4. Export `DB_VERSION` as `const DB_VERSION = 1`.

    5. Export `getDB()` as an async function. Inside: if `dbInstance` is non-null, return it. Otherwise call `openDB<NowPilotDB>('nowpilot', DB_VERSION, { ... })` with:
       - `upgrade(db, oldVersion, newVersion, transaction)`: When `oldVersion < 1`, create all 13 object stores with exact keyPaths and indexes listed above. Use `db.createObjectStore(name, opts)` where `opts` is `{ keyPath: 'id' }` for single-key stores and `{ keyPath: ['conversationId', 'seq'] }` for the compound-key `memory_messages` store. After creating `chat_history_messages`, call `store.createIndex('by-session', 'sessionId')`. After creating `write_journal_entries`, call `journalStore.createIndex('by-status', 'status')`.
       - `blocked()`: Call `debugLog('warn', 'IndexedDB: open blocked by older connection')`.
       - `blocking()`: Call `dbInstance?.close()` then `dbInstance = null`.
       - `terminated()`: Call `debugLog('error', 'IndexedDB: connection terminated unexpectedly')` then `dbInstance = null`.

    6. Store the result in `dbInstance` and return it.

    7. Do NOT add `export const indexedDBManager = new IndexedDBManager()` — this is NOT a class. The module itself is the singleton via the module-scoped `dbInstance` variable.

    8. Run `npx tsc --noEmit` from the project root to verify the file compiles.
