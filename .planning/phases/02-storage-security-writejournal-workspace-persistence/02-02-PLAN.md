<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Every surface → IndexedDB | Extension pages are the only writers; the background service worker must never open the database (§0.2). |
| Legacy/persisted data → repositories | Records read from the database cross a validation boundary and may be malformed or tampered. |
| Journal record → durable storage | The journal is written on every step and must carry no body or secret. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-06 | Information Disclosure | `ChatHistoryDB` write path | high | mitigate | Bodies live only in `sessions`/`messages`; the end-to-end case asserts the body substring is absent from the serialised local and session storage maps, and the journal schema has no body field. |
| T-02-07 | Tampering | `IndexedDBMigrator` upgrade | high | mitigate | Existence checks before every `createObjectStore`/`createIndex`; a failing step is captured as a redacted result before the deliberate rethrow; `VersionError` maps to a typed unsupported-version error that is never retried. |
| T-02-08 | Tampering | journal replay | high | mitigate | Deterministic idempotency keys and idempotent `apply()`; the replay case asserts the destination ends with one record, not two. |
| T-02-09 | Denial of Service | blocked upgrade | medium | mitigate | `blocked` records a typed signal and degrades instead of waiting; `blocking` closes the older connection so the upgrade cannot hang (both paths asserted). |
| T-02-10 | Repudiation | journal state after a crash | medium | mitigate | Stages are pre-seeded and persisted after every transition, so a restart can distinguish "not reached" from "reached"; `recoverJournal` replays both `pending` and `applying`. |
| T-02-11 | Elevation of Privilege | background service worker | high | accept | The database is not imported by any background module; the existing isolation suites plus 02-10's surface wiring keep `src/entrypoints/background.ts` unchanged. |
| T-02-SC | Tampering | npm installs | high | mitigate | No install happens in this plan; the packages landed in 02-01 with the legitimacy audit already recorded. |
</threat_model>
