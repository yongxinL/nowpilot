<objective>
Create the EncryptedStorage class — a transparent AES-GCM-256 encryption wrapper around `chrome.storage.local` that encrypts values before persistence and decrypts them on retrieval. Implements D-10 (transparent wrapper, same get/set/remove API surface), D-11 (PBKDF2 key derivation from install secret), D-12 (per-value unique salt+IV), D-13 (initialize at startup, lazy auto-init fallback), D-14 (AES-GCM-256 via crypto.subtle).

Purpose: API keys and other sensitive data must never be stored in plaintext. EncryptedStorage provides zero-touch encryption — consumers call `set`/`get`/`remove` without needing to know encryption is happening. The `providerStore` in Plan 08 will consume this.

Output: `src/core/storage/EncryptedStorage.ts` with EncryptedStorage class, `encryptedStorage` singleton export, EncryptedPayload type, and comprehensive tests.
</objective>

    Create `src/core/storage/EncryptedStorage.ts`. Per RESEARCH.md Pattern 2, this is a class with singleton export.

    CONCRETE IMPLEMENTATION REQUIREMENTS:

    1. Import `debugLog` from `'../utils/debugLog'`.

    2. Export interface `EncryptedPayload` with fields:
       - `alg: 'AES-GCM'` (literal string type)
       - `salt: number[]` (serialized as number array for chrome.storage JSON compatibility — NOT ArrayBuffer)
       - `iv: number[]` (serialized as number array)
       - `ciphertext: number[]` (serialized as number array)

    3. Export class `EncryptedStorage` with:
       - `private masterKey: CryptoKey | null = null`
       - `private initialized = false`

    4. Public method `async initialize(): Promise<void>` — per D-13:
       a. Call `this.getOrCreateInstallSecret()` to obtain the install secret string.
       b. Get `const extensionId = chrome.runtime.id`.
       c. Import key material: `crypto.subtle.importKey('raw', new TextEncoder().encode(installSecret + extensionId), 'PBKDF2', false, ['deriveKey'])`.
       d. Create master salt: `const masterSalt = new TextEncoder().encode('np-master-' + extensionId)`.
       e. Derive key: `crypto.subtle.deriveKey({ name: 'PBKDF2', salt: masterSalt, iterations: 100000, hash: 'SHA-256' }, keyMaterial, { name: 'AES-GCM', length: 256 }, false, ['encrypt', 'decrypt'])`.
       f. Store in `this.masterKey`. Set `this.initialized = true`.

    5. Public method `async set(key: string, value: unknown): Promise<void>` — per D-12:
       a. Call `await this.ensureInitialized()`.
       b. Generate `const salt = crypto.getRandomValues(new Uint8Array(16))`.
       c. Generate `const iv = crypto.getRandomValues(new Uint8Array(12))`.
       d. Serialize value: `const plaintext = new TextEncoder().encode(JSON.stringify(value))`.
       e. Encrypt: `const ciphertext = await crypto.subtle.encrypt({ name: 'AES-GCM', iv }, this.masterKey!, plaintext)`.
       f. Convert ArrayBuffers to number arrays for chrome.storage compatibility: use `Array.from(new Uint8Array(buf))` for salt, iv, and ciphertext.
       g. Construct payload: `const payload: EncryptedPayload = { alg: 'AES-GCM', salt: Array.from(new Uint8Array(salt)), iv: Array.from(new Uint8Array(iv)), ciphertext: Array.from(new Uint8Array(ciphertext)) }`.
       h. Persist: `await chrome.storage.local.set({ [key]: payload })`.

    6. Public method `async get<T = unknown>(key: string): Promise<T | null>`:
       a. Call `await this.ensureInitialized()`.
       b. Read: `const result = await chrome.storage.local.get(key)`.
       c. Extract: `const payload = result[key] as EncryptedPayload | undefined`. If `!payload`, return `null`.
       d. Convert number arrays back to Uint8Array: `new Uint8Array(payload.iv)`, same for ciphertext.
       e. Decrypt: `const plaintext = await crypto.subtle.decrypt({ name: 'AES-GCM', iv: ivArray }, this.masterKey!, ciphertextArray)`.
       f. Parse: `return JSON.parse(new TextDecoder().decode(plaintext)) as T`.

    7. Public method `async remove(key: string): Promise<void>`:
       - `await chrome.storage.local.remove(key)`.

    8. Private method `async getOrCreateInstallSecret(): Promise<string>` — per D-11:
       a. `const result = await chrome.storage.local.get('np_install_secret')`.
       b. If `result.np_install_secret` exists as string, return it.
       c. Otherwise, generate 32 random bytes: `crypto.getRandomValues(new Uint8Array(32))`, convert to hex string using `Array.from(bytes).map(b => b.toString(16).padStart(2, '0')).join('')`.
       d. Store: `await chrome.storage.local.set({ np_install_secret: secret })`.
       e. Return secret.

    9. Private method `async ensureInitialized(): Promise<void>` — per D-13 lazy auto-init:
       - `if (!this.initialized) await this.initialize()`.

    10. Export singleton: `export const encryptedStorage = new EncryptedStorage()`.

    11. Run `npx tsc --noEmit` to verify compilation.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| EncryptedStorage → crypto.subtle | Web Crypto API — correctness of encrypt/decrypt depends on browser implementation |
| EncryptedStorage → chrome.storage.local | Encrypted payloads stored — plaintext never crosses this boundary |
| chrome.storage.local → other extension contexts | `np_install_secret` is readable by any extension context (same origin) |

| T-02-04 | Elevation of Privilege | `np_install_secret` in chrome.storage.local | low | accept | `chrome.storage.local` is extension-scoped — not accessible to web pages. Accepted per Chrome MV3 security model. |
