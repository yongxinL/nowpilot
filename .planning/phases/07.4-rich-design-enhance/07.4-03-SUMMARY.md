## Decisions Made

- **TemplateBrowserService methods are async** — PromptManager.getAllTemplates() returns a Promise (async persistence). The service layer correctly awaits this at the async boundary.
- **generateGreeting uses Date-based computation with no side effects** — Pure function with no I/O, no class, no dependencies. Enables direct testing via `vi.setSystemTime()` without mocking.
- **TemplateBrowser uses useEffect with cancellation flag** — The component loads categories asynchronously when the popover opens. A `cancelled` flag in the effect cleanup prevents stale state updates when the popover is rapidly opened and closed.
- **SnippetsOutlined used instead of TemplateOutlined** — The `TemplateOutlined` icon referenced in the plan/RESEARCH.md does not exist in `@ant-design/icons` v6.3.2. `SnippetsOutlined` is the semantically closest available icon for "template/snippet browsing".
- **displayCategory assigned per PATTERNS.md** — Writing (18 templates), Analysis (2: summarize, testing), Research (1: explain), Coding (0: empty for future), Support (0: empty for future)
- **No Coding/Support templates yet** — The displayCategory values exist for future use but currently have 0 templates assigned.
