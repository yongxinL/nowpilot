**RightPaneStore with selective persist (partialize whitelist), collapsible RightPane container with antd Tabs (Context/Notes/Tools), PaneToggle with compact→expanded→collapsed cycle, and tab components with UI-SPEC empty states — all built TDD-style with 18 passing tests**

## Accomplishments

- **RightPaneStore** (Zustand + persist + chrome.storage.local adapter) with `np_right_pane` key and explicit `partialize` whitelist — 3 UI fields persisted (activeTab, visible, width), 3 transient fields excluded (searchQuery, selectedNoteId, expandedToolId) per Pitfall 1
- **RightPane** container with antd Tabs hosting three tab panels (Context, Notes, Tools), width-controlled via prop for parent layout integration
- **PaneToggle** divider button with 3-state cycle (compact→expanded→collapsed→compact) using combined width + visible store flags; title attribute reflects current state for accessibility
- **ContextTab** reading `currentPageContext` + `pinnedTabs` from workspaceStore via individual selectors; empty state: "No page context" + pin hint per UI-SPEC
- **NotesTab** with Input.Search placeholder and inline preview scaffolding; empty state: "No notes yet" + "Create a note..." per UI-SPEC
- **ToolsTab** with Collapse/Accordion for expandable tool details; empty state: "No tools configured" + MCP hint per UI-SPEC
- All tabs use antd `theme.useToken()` for consistent typography (14px body, 16px heading, 2 weights: 400/600) and spacing contracts

## Decisions Made

- **RightPaneStore partialize whitelist** follows diagnosticsStore.ts pattern exactly — whitelist only `{ activeTab, visible, width }` to prevent transient state leakage (Pitfall 1)
- **3-state toggle cycle** implemented in PaneToggle component (not store) using combined `width` + `visible` flags: compact (visible=true, width='compact') → expanded (visible=true, width='expanded') → collapsed (visible=false) → compact
- **Tab components** follow PinTabBar pattern with individual Zustand selectors (`s => s.activeTab`, etc.) to prevent re-renders on unrelated state changes
- **Empty states** match UI-SPEC copywriting contract exactly: "No page context", "No notes yet", "No tools configured" with corresponding help text
