## Decisions Made

- **ConfirmationLevel tool mapping:** summarize_page/extract_page → AutoExecute, web_search/web_fetch → ConfirmInline, send_message/create_record/update_record → RequirePermission. Unknown tools default to RequirePermission (default-deny).
- **responseBrevity string mapping:** 'concise' maps to existing default "Concise by default with task-aware expansion"; 'detailed' maps to "Detailed with thorough explanations". These strings are consumed by PersonaInjector for system prompt construction.
- **Explicit field-level assignment:** Per RESEARCH.md Pitfall #4, getActiveProfile() uses explicit `profile.identity = { ...profile.identity, name: prefs.aiName }` instead of deep spread, preventing nested-object corruption.
- **ConfirmationPolicy import path:** From PermissionService.ts (`src/core/ai/tools/`) the import resolves to `../../confirmation/ConfirmationPolicy`.
