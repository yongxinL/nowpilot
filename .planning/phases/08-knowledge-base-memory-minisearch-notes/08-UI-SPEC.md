> Visual and interaction contract for the Phase-8 core-logic surfaces. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

## Phase Scope Boundary (read first)

**Phase 8 is a data-layer + core-logic phase, NOT a full UI phase** (spec §18 Phase 8 block, lines 2656-2696). It ships exactly three `.tsx` files carrying **core logic only** — `src/components/notes/{BacklinksPanel, WikilinkAutocomplete, NoteGraphView}.tsx` — which the Phase-15 `NotesWorkspace` (4-column Notes UI, DESIGN_SYSTEM §8.3) consumes (D-111). **This contract governs those three thin components' data contracts, minimal rendering, and interaction affordances as consumed at Phase 15.**

**Out of this contract's scope** (do NOT design here): the full Notes workspace (list/editor/backlinks/graph/search) — Phase 15.1; memory UI (Options → Memory / Persona editors, REQ-F28/F33) — Phase 15; "Ask your notes" RAG bar (LLM-WIKI-06) — Phase 15.2; LLM-wikilink autocomplete suggestions — not in v0.1 (D-04); `search-notes` tool UI — Phase 18; note deletion / sync confirmations — Phase 9/15.

**Design authority (DESIGN_SYSTEM §8.0 precedence rule):** functional rules → `PRODUCT_SPEC_v0_1.md`; visual layout intent → `.planning/mockup/` (`02-standalone-note.png` for Notes); token values → `.planning/DESIGN_SYSTEM.md` + `src/theme/`. Phase-8 components reuse existing AntD v6 tokens — they introduce **zero new tokens, zero new packages**.

## Component Interaction Contracts (core-logic surfaces)

### 1. `BacklinksPanel.tsx` — backlink listing core (D-111) + thin list

**Data contract (core logic):**
- `BacklinkEntry { noteId: string; title: string; updated: number }` — reverse index over `links[]`; **sorted `updated` desc**.
- Entries with dangling IDs (deleted notes) are excluded after graph rebuild / save reconciliation (WIKI-ID-04 demotion — `links[]` membership is computed against the live note set).
- Count = number of backlink entries.

**Props:** `{ noteId: string; onSelect: (noteId: string) => void; maxItems?: number }`

**Rendering contract (thin):**
- Scrollable list sized to its Phase-15 container (Inspector column 4, §8.3); `colorBgContainer`, radius 12, `E1`.
- Header row "BACKLINKS" (11 px uppercase, `colorTextTertiary`) + count `Tag`.
- Row: title (`colorPrimary`, hover underline, single-line ellipsis, hit target ≥ 32/36 px) + relative time (`colorTextTertiary`, 12 px).
- Empty state: declared copy above; never a blank surface.

**Interaction:** row click → `onSelect(noteId)` (Phase 15 navigates the editor); rows are real `<button>`s — keyboard-focusable, 2 px `colorPrimary` focus ring, aria-label "Open backlink {title}".

### 2. `WikilinkAutocomplete.tsx` — MiniSearch title-match core (D-04/D-111) + thin popover

**Data contract (core logic):**
- `WikilinkSuggestion { noteId: string; title: string }` — query = text after `[[`; MiniSearch **title** search (per-surface `MiniSearchIndex`), top-k (≤ 10), ties broken `updated` desc → `id` asc (WIKI-ID-02).
- **No LLM suggestions in v0.1** (D-04) — title matching only.

**Props:** `{ query: string; open: boolean; onSelect: (s: WikilinkSuggestion) => void; onClose: () => void }` — the `[[` trigger + caret anchoring is Phase-15 editor integration; this component consumes query + open.

**Rendering contract (thin):**
- Popover anchored to the caret: `colorBgElevated`, `E2` elevation, radius 12, max-height 240 px with internal scroll.
- Row: title (single-line ellipsis, 13/14 px); active row `colorPrimaryBg` fill + `colorPrimaryText`.
- Empty state: declared copy above.

**Interaction:**
- Keyboard: `↑`/`↓` move active row, `Enter` accept, `Esc` dismiss; click accepts.
- A11y: `role="listbox"` + `role="option"` + `aria-selected`; focus remains in the editor (Phase 15 wiring); 2 px `colorPrimary` focus ring.

### 3. `NoteGraphView.tsx` — graph adjacency/rendering-data core (D-111) + thin scaffold

**Data contract (core logic):**
- `GraphNode { id: string; title: string; kind: 'current' | 'similar' | 'backlink' }`
- `GraphEdge { source: string; target: string; type: 'similar' | 'backlink' }`
- Nodes from `topKSimilar(note, k = 5)` (§22.3 bag-of-words cosine + 50-word inline stop-list) + backlinks reverse index; current note = center node.

**Props:** `{ noteId: string; onSelect: (noteId: string) => void }`

**Rendering contract (thin):**
- Renders the adjacency data legibly (SVG or container scaffold): current node `colorPrimary` fill; similar/backlink nodes `colorBgContainer` with `colorBorder`, title in `colorPrimary` on select.
- **The full d3-force graph view is Phase 15** (FEATURES.md "graph view (d3-force)") — Phase 8 ships the data contract + a legible thin render, not the final layout engine.
- Empty state: declared copy above.

**Interaction:** node click → `onSelect(noteId)`; hover highlight; hit target ≥ 32/36 px.

### Cross-component security contract (all three)
- Note titles/content are **untrusted data** (CTX-02, Phase-7 trust layer): render through React JSX text nodes only — **no `dangerouslySetInnerHTML`** (research Security Domain; grep-assertable). Phase-15 body rendering uses `PortableMarkdown` (spec §16.1).
- Run in UI contexts only (side panel / standalone) — never the background SW (MV3, §5.2).
- New Phase-8 code is strict-clean: zero `@ts-expect-error NP-STRICT` markers (STATE.md decision 17).
