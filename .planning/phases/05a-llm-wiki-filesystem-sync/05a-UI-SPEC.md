# Phase 05a — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Phase character:** Phase 5a builds **core services only** — `NoteTagger`, `NoteQA`, `NoteChatConverter`, `NoteFileSync`, `NoteMaintenance` in `src/core/notes/` + shared `LlmService` in `src/core/ai/`. No UI components ship in this phase (per RESEARCH.md Architectural Responsibility Map: all capabilities are API/Backend tier; UI consumption is Phase 7). This contract therefore pins the **interaction contracts the services expose** — events, status shapes, copy strings, and confirmation flows — so Phase 7 planners/executors can wire UI against them and the retroactive auditor has a prescriptive baseline. All copy and behavior below is locked by PRODUCT_SPEC §27, Flows 12–15, and §19.16–19.19 (canonical refs in 05a-CONTEXT.md).

## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, Tag padding, inline suggestion gaps |
| sm | 8px | Compact element spacing, Tag/suggestion rows |
| md | 16px | Default element spacing, card padding, modal padding |
| lg | 24px | Section padding, panel gaps, dialog internal sections |
| xl | 32px | Layout gaps between major regions (editor ↔ inspector) |
| 2xl | 48px | Major section breaks, empty-state vertical rhythm |
| 3xl | 64px | Page-level spacing (Full App surfaces) |

Exceptions:
- **Button control height 36px** (theme-locked `Button.controlHeight: 36`) — intentional exception to the 44px touch-target guidance; do not raise per-element.
- **Radii:** `borderRadius` 24 (cards/modals), LG 24, SM 16, XS 12; primary buttons use pill radius 999 (all theme-locked in liquid-glass/claude).
- **Restore/dialog preview rows:** dense rows may use 12px (3×xs) internal rhythm for count metadata — still on the 4px grid.

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px | 400 | 1.5 |
| Label | 12px | 600 | 1.5 |
| Heading | 16px | 600 | 1.2 |
| Display | 20px | 600 | 1.2 |

- Exactly 4 sizes, 2 weights (400 regular + 600 semibold). No weights below 400 or above 600.
- **Role mapping:** Body = note content, RAG answer body, dialog descriptions. Label = Tags, status Tags ("Backup: On"), badges ("Orphan"), toolbar buttons, category tree nodes, count metadata. Heading = note titles, card headers, section titles, dialog titles. Display = page titles (Notes surface header, Options section headers), RAG answer title.
- **Migration note:** the existing `NotesWorkspace.tsx` mockup uses 10–11px micro-text (`text-[10px]`, `text-[11px]`) for counts/links — Phase 7 consumers must use ≥12px Label for all readable text; 10–11px is not part of this contract.
- Summary field renders as secondary text in NoteList at 14px/400/1.5 with `colorTextSecondary` (LLM-WIKI-03).

## Color

Values are the locked liquid-glass theme tokens (light / dark). Semantic colors use antd defaults unless overridden.

| Role | Value (light / dark) | Usage |
|------|----------------------|-------|
| Dominant (60%) | `#f4f5f7` / `#090b0f` (colorBgBase) | Page/workspace background, empty regions |
| Secondary (30%) | `#ffffff` / `#13161b` (colorBgContainer); elevated `#ffffff` / `#1a1d22` (colorBgElevated) | Cards, note editor canvas, panels, dialogs, popovers, dropdowns, Tag surfaces |
| Accent (10%) | `#297cef` / `#3a8cff` (colorPrimary) | Primary CTAs, active/selected list states, citation Tags, links, focus ring (`--np-ring`), "AI Search" indicator |
| Success | antd colorSuccess: `#52c41a` / `#49aa19` | "Backup: On" Tag, restore "X new" counts, success messages |
| Warning | antd colorWarning: `#faad14` / `#d89614` | "Backup: Paused" (permission 'prompt'), external-change hint, stale-content hint |
| Destructive | antd colorError: `#ff4d4f` / `#e84749` | "Backup: Error" Tag, overwrite-confirm action, delete-note action, error text |

Accent reserved for: **primary buttons (Set backup folder, Restore from folder, Import, Save to note, Regenerate tags/summary, Re-analyze all notes, New Note), selected category/note states, citation Tags in the RAG Bubble, inline links to source notes, focus rings, the AI-enhanced search indicator.** Never applied wholesale to "all interactive elements" — secondary actions stay default/outlined.

Text roles: primary text `#0c121a` / `#f0f2f4` (colorText); secondary `#565e69` / `#8f9aa4` (colorTextSecondary); borders `#dbdee2` / `#26292e` (colorBorder). All surfaces must remain theme-resolved — never hardcode light values into dark mode.

## Service → UI Interaction Contract

Phase 5a ships the services; this section is the binding contract between each service surface and its Phase 7 rendering. Each row names the implemented API/event (verified in `src/core/notes/`) and the exact UI behavior it mandates.

| Service surface | Contract (implemented API) | Mandated UI behavior |
|-----------------|----------------------------|----------------------|
| `note:saved` event `{ noteId, version }` | NotesDB emits on every save (parallel independent subscribers, D-17) | Must never block the save flow; UI shows no save delay. |
| `note:enriched` event `{ noteId, enrichment, memoryFacts }` | NoteTagger emits after async haiku call; stale results silently discarded (D-05/D-07) | Two independent review surfaces (D-02): (1) enrichment → **inline accept/reject on the note editor** — Tags for tags, category input for categoryPath, summary field, concept chips; (2) memoryFacts (≤3, confidence ≥0.3 filtered, D-04) → **separate "New Memory Facts" notification/side-panel flow**. Suggestions are in-memory only (lost on restart; "Regenerate" is the recovery path). |
| `sync:error` event `{ noteId?, error, reason }` | reason ∈ `permission_denied \| handle_expired \| not_allowed \| error` | Backup status flips red "Backup: Error"; tooltip carries `error`; on NotesPage mount with denied permission show "[Re-select folder] [Dismiss]" banner (D-10). |
| `sync:external-change` event `{ noteId, title, localModified, fileModified }` | Emitted when file.lastModified > lastSyncedAt + 2s | Modal confirm "This file was modified externally. Overwrite with app version? [Overwrite] [Skip]", **default Skip**; Skip writes the note to a collision-suffixed file so the user's newer file is never touched. |
| `getSyncStatus()` → `SyncStatus { enabled, handleExists, permissionState: 'granted'\|'denied'\|'prompt'\|'unknown', lastSyncAt?, error? }` | Single status accessor | Tag mapping: enabled+granted → green "Backup: On"; no handle → gray "Backup: Off" (+[Configure]); denied → red "Backup: Error"; prompt/unknown with handle → "Backup: Paused". Checked on NotesPage mount; re-select prompt on denial. |
| `setBackupFolder()` | Wraps `showDirectoryPicker()` — requires user gesture, Full App only (SYNC-01) | Triggered by "Set backup folder" button; on success Tag → green "Backup: On". No loading state (fire-and-forget, SYNC-03). |
| `restoreFromFolder()` → `RestoreResult { preview: { total, newCount, updatedCount, unchangedCount, skippedCount }, notes[] }` | Additive upsert; never deletes local notes (SYNC-09/10) | Preview modal first: "Found {N} notes ({X} new, {Y} updated, {Z} unchanged). Proceed? [Import] [Cancel]"; skipped files (malformed/duplicate id) count toward `skippedCount` with tooltip explanation. |
| `NoteQA.ask()/search()` → `{ answer, citations[] }` (citations: `{ noteId, title, relevantSnippet, referenceNumber }`) | flash-tier synthesis with numbered `[1]` markers (D-13); `TINY` tier returns raw snippets with noteId links, no LLM (D-16) | "Ask notes" bar (Flow 13): answer renders as ephemeral `@ant-design/x` Bubble; citation markers render as **clickable Tags** navigating to the source note; tiny-tier output renders as raw result list with note links; zero hits → "No relevant notes found. Try rephrasing." without an LLM call. |
| `NoteChatConverter.convert()` → `NoteDraft { title, content, tags, categoryPath, wikilinks }` | haiku draft with memory context (MEM-03); provenance `chat-conversion` on save | SaveToNoteDialog with pre-filled NoteEditor + NotePreview — **user is always the gatekeeper** (Flow 12); wikilinks in draft remain proposals until user accepts (KNW-01 deferral). |
| `NoteMaintenance.getStaleNotes()/getOrphanNotes()/reanalyzeAll()` → `ReanalyzeResult { total, enriched, failed }` | Passive, UI-driven queries (D-21) | Stale notes → "Content has changed — [Regenerate tags/summary]" hint (LLM-WIKI-08); orphans → "Orphan" badge + "Find context" (LLM-WIKI-09); Re-analyze all runs sequentially and must surface per-note and final progress ({enriched}/{total}, failed count). |
| `NoteTaggerToggles { autoTag, autoCategorize, autoSummary, memoryExtraction }` | D-06: all three enrichment toggles off → no LLM call; memoryExtraction off → call runs, facts discarded | Options → Notes switches (key `np_notes_llm_features`); all-off state must render no "Analyzing…" affordance since no call fires. |

**Non-negotiable invariants:** save never waits on the LLM (D-07); sync never shows a loading state (fire-and-forget, SYNC-03); enrichment is never auto-applied (D-15 user-gated); memory writes gate at `MemoryEngine.write()` via `isPrimarySurface()` (D-19 — enrichment suggestions may render on both surfaces, writes only commit on primary); all LLM responses pass Zod validation before rendering (note content is untrusted input — render via markdown, never raw HTML).
