<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ServiceNowSidepanelPage → ServiceNowSessionAdapter | Session acquisition may expose credentials to UI layer — session object should be minimal |
| ServiceNowStandalonePage → ServiceNowTableClient | Case data from external API rendered in UI — must handle malicious response content |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-16 | Information Disclosure | ServiceNowSidepanelPage | medium | mitigate | Session credentials (JSESSIONID, sysparmCK) stay in ServiceNowSessionAdapter — page components receive only case metadata (number, title, state). No raw session data exposed to UI. |
| T-08-17 | Spoofing | ServiceNowStandalonePage Table | low | accept | Case data from ServiceNow API is user's own instance data — spoofed responses would require MITM of HTTPS connection. Chrome platform handles TLS. Accept. |
| T-08-18 | Elevation of Privilege | ServiceNow skill execution | low | accept | Skills are prompt templates executed through existing AI pipeline — same permission model as all other prompts. Accept. |
</threat_model>
