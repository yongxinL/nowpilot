## Spacing Scale

Declared values (Ant Design token-based, base unit 8px):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, compact button padding |
| sm | 8px | Compact element spacing, SiderMenuItem gaps, nav item padding |
| md | 16px | Default element spacing, Card body padding, Form item gaps |
| lg | 24px | Section padding, Card gaps in ImportExportSection |
| xl | 32px | Layout gaps, Options section max-width offset |

**Exceptions:**
- Side Panel sider widths: expanded = 60px, narrow = 44px (from `SIDEPANEL_SWITCHBAR_WIDTH`, `SIDEPANEL_NARROW_WIDTH`)

## Typography

| Role | Size | Weight | Line Height | Ant Design Token |
|------|------|--------|-------------|------------------|
| Body | 14px | 400 (regular) | 1.5715 (22px) | fontSize, lineHeight |
| Label / Secondary | 12px | 400 (regular) | 1.6667 (20px) | fontSizeSM |
| Heading (Card titles) | 16px | 600 (semibold) | 1.5 (24px) | fontSizeLG, fontWeightStrong |
| Page Title (h4) | 20px | 600 (semibold) | 1.4 (28px) | fontSizeHeading4 |

**Rules:**
- No custom font sizes beyond Ant Design tokens — use `token.fontSize`, `token.fontSizeSM`, `token.fontSizeLG`, `token.fontSizeHeading4`
- Only two weights: regular (400) and semibold (600), via `token.fontWeightStrong`
- All Typography primitives use Ant Design `<Typography.Title>`, `<Typography.Text>`, `<Typography.Paragraph>` — no raw `<h1>`-`<h6>` or `<p>` for typed content

**Source**: Ant Design v6 default token system, existing component patterns in `ImportExportSection.tsx`, `AddonSettingsSection.tsx`

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `token.colorBgContainer` | Page backgrounds, Card bodies, Form surfaces |
| Secondary (30%) | `token.colorBgElevated` | Cards, sidebar, nav, elevated surfaces |
| Accent (10%) | `token.colorPrimary` (#e0582e) | Primary buttons (type="primary"), active nav items, links, focus rings, checkboxes/radio checked states |
| Destructive | `token.colorError` (Ant Design default red) | Destructive action buttons, error alerts, validation error text |

**Accent reserved for:** Primary CTA buttons, active nav item indicators, checkbox/radio checked states, link text, focus rings. Never for: decorative elements, backgrounds, borders (use `colorBorderSecondary`).

**Dark mode:** All colors reference Ant Design tokens (`colorBgContainer`, `colorBgElevated`, `colorPrimary`, `colorError`) — dark variants are automatically provided by `darkAlgorithm`.

**Source**: `src/core/theme/antdConfig.ts` (colorPrimary token), existing component patterns

## Page-Level Layout Contract

### Side Panel Pages (compactAlgorithm)
All add-on Side Panel pages conform to SidepanelContent constraints:
- **Max width**: 100% of available content area (SidepanelSider + SidepanelContent layout)
- **Padding**: 16px (token.paddingMD) inner padding
- **Header**: No separate header — page title rendered as `<Typography.Title level={4}>` at top of content
- **Scroll**: vertical overflow-y: auto, no horizontal scroll
- **Empty states**: `<Empty>` component centered with 48px padding

### Full App Pages (defaultAlgorithm)
All add-on Full App pages render within StandaloneContent:
- **Max width**: 100% of content area (right of sider, left of RightPane if active)
- **Padding**: 24px (token.paddingLG) inner padding
- **Header**: Page title as `<Typography.Title level={4}>` at top of content
- **Data tables**: Use Ant Design `<Table>` with `size="middle"`, pagination, and row selection where applicable

**Source**: `src/components/sidepanel/SidepanelContent.tsx`, `src/components/standalone/StandaloneContent.tsx`

## Interaction Patterns

### Write Add-on (Side Panel)
1. **Nav entry**: Write icon appears in Side Panel sider (group: 'addons', below separator)
2. **Page load**: 6 quick-action buttons rendered as a vertical `<Card>` with action list layout
3. **Skill invocation**: User clicks a skill button (e.g., "Rewrite") → Sender is populated with the corresponding prompt template
4. **Prompt templates**: Each skill button maps to a PromptManager template; system prompt + placeholder variables are pre-populated
5. **No streaming from button click alone** — the button populates the Sender; user must press Send to execute

**Skills and labels** (D-07):
- Rewrite → "Rewrite selected text"
- Summarize → "Summarize this content"
- Draft Customer Update → "Draft a customer update"
- Draft Internal Note → "Draft an internal note"
- Explain → "Explain this to me"
- Action Plan → "Create an action plan"

### ServiceNow Add-on
1. **Session acquisition** (Side Panel): On first access, prompt for cookie permission via PermissionDialog (Allow once / Allow always / Deny)
2. **Side Panel page**: Compact case-context Card showing current case number, short description, priority, state. Below: skill launcher buttons (CaseAnalyzer, CatchUp, Sentiment)
3. **Full App page**: `<Table>` with columns (Number, Short Description, Priority, State, Assigned To, Updated). Row click opens detail `<Drawer>` with Comments and Work Notes tabs
4. **API calls**: All ServiceNow Table API calls route through PROXY_FETCH — no bare fetch()
5. **Session freshness**: On-demand re-extraction when session expires — no polling

### TeamGQM Add-on
1. **Side Panel page**: Read-only `<Tree>` with `defaultExpandAll` on load. Three levels: Goal → Question → Metric. Each metric shows name + current value
2. **Full App page**: Editable `<Tree>` with inline editing (`editable` prop). Context menu or inline buttons for Add Goal / Add Question / Add Metric
3. **Data persistence**: All writes through WriteJournal into IndexedDB (D-11). Dedicated object store or namespaced within NotesDB

### ResearchSkill (Global Add-on)
1. **Invocation**: `/research` slash command in Chat or Agent page
2. **Available**: Graceful degradation — if no search MCP server connected, show `<Alert type="info">` with: "Configure a web search tool in Options → Skills & MCP to enable research."
3. **Execution**: When MCP search is available, runs the search + synthesizes results inline as a streaming response

### AddonSettingsSection
1. **Layout**: Replace `<Empty>` stub with a vertical list of registered add-ons
2. **Per add-on**: `<Card>` with add-on name, description, and `<Switch>` for enable/disable
3. **Settings form**: Expands below the Card when add-on is enabled — renders add-on's registered settings schema as Ant Design `<Form>` items
4. **Save**: Per-addon "Save" button; settings persisted to `chrome.storage.local` under `np_addon_settings` namespace

### ImportExportSection (Enhanced)
1. **Export**: Existing flow unchanged; adds WriteJournal `export-data` operation wrapping for atomic snapshot
2. **Import merge**: Deterministic timestamp-based merge (`updatedAt` comparison, latest-wins). No interactive conflict resolution — automatic with summary alert of merge results
3. **Credential exclusion**: Before writing export file, apply TraceRedactor as safety net. Dedicated test verifies no API keys, encrypted payloads, or session tokens in output
4. **Progress**: `<Progress>` component already exists in export flow — no change needed

## Implementation Constraints

1. **No tailwind, no shadcn, no Radix UI** — all UI uses Ant Design primitives and tokens exclusively
2. **No raw HTML elements for typed content** — use `<Typography.Title>`, `<Typography.Text>`, `<Typography.Paragraph>`
3. **All messages/notifications via `App.useApp()`** — never `message` static import
4. **All API calls through PROXY_FETCH** — ServiceNow Table API, any add-on external requests
5. **Add-on components in `src/addons/[name]/components/`** — not in `src/components/`
6. **Core never imports from addons** — enforced by `tests/core/no-addon-imports.test.ts` (ADDON-10)
7. **WriteJournal for all IndexedDB writes** — add-on data stores, export operations
8. **All new pages registered via `SidepanelPageRegistry` or `StandalonePageRegistry`** — follow `registerCorePages.ts` blueprint pattern
9. **SidepanelSiderWidths**: add-on pages must not assume fixed widths; use flex/percentage-based layouts
10. **No emoji in UI copy** — use Ant Design icons or text labels only
