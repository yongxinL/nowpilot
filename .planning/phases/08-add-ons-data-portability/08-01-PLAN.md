<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| addon code → AddonRegistry | Addon registration functions call register* methods — registry validates no duplicates |
| chrome.storage.local → AddonRegistry | Enable/disable state loaded from chrome.storage.local — potentially tampered by other extensions |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-01 | Elevation of Privilege | AddonRegistry | high | mitigate | D-02/D-03: registration != execution. Enable state gated by chrome.storage.local persisted flag. getEnabledSkills/getEnabledPages filter disabled addons. User must explicitly enable in Options. |
| T-08-02 | Tampering | chrome.storage.local np_addon_enabled | medium | accept | chrome.storage.local is extension-isolated — other extensions cannot write to NowPilot's storage keys. Accept as platform guarantee. |
| T-08-03 | Denial of Service | AddonRegistry register* | low | accept | Duplicate registration throws — prevents accidental double-registration. No DoS vector beyond programming error. |
</threat_model>
