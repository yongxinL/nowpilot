## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| MemoryDB (IndexedDB) → UserMemoryStore reads | persisted user facts cross into retrieval — tampered/malformed rows must not crash or poison scoring |
| working-memory write path | user-supplied profile text crosses into storage — secrets must be redacted before persist (R-10) |
| legacy Fact rows (v1) → v2 | pre-migration rows cross the upgrade boundary — data must survive, defaults must fill |

|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-04 | Information Disclosure | working-memory write path (updateWorkingMemory) | high | mitigate | O.10 VERBATIM: every patch value passes TraceRedactor.redact before the markdown merge (R-10); the store never logs raw profile text (debugLog extra = field names only); test pins the redaction with a secret-shaped fixture |
