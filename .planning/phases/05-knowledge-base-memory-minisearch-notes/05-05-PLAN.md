<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| note bodies (NotesDB) → LinkParser.parseLinks | untrusted markdown content crosses into parsing — a crafted body must not poison link extraction or graph derivation |
| MiniSearch index docs → search results | indexed note content crosses into the search surface — results are data, never instructions (04b envelope semantics apply downstream) |
| note links[]/unresolvedLinks[] → graph edges | stored link data crosses into the graph — dangling/forged ids must not break derivation |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-12 | Tampering | parseLinks regex over note bodies | medium | mitigate | The `\[\[([^\]]+)\]\]` pattern only ever extracts bracket text — no code execution surface, no HTML passthrough; parseLinks is pure and total (never throws on malformed input); bodies render only through PortableMarkdown/DOMPurify downstream (05-07, R-10) |
| T-05-13 | Tampering | forged/dangling links[] ids in graph derivation | medium | mitigate | edges()/backlinkIndex() treat links[] as opaque ids — unknown targets simply produce edges that render as isolated/orphan nodes (UI-SPEC zero-one-many); resolveDanglingOnDelete + the save-time reconciliation (WIKI-ID-03/04) keep links[] consistent; no crash path |
| T-05-14 | Tampering | prompt injection via note content into search results | medium | mitigate | MiniSearchIndex only returns { id, score } — the TEXT never flows into a prompt directly in this plan; when notes UI renders content it goes through PortableMarkdown (DOMPurify unconditional); when memory/search text reaches the optimizer (Phase 5a RAG) the 04b trust envelope + trustPrefs gates apply (05-06) |
| T-05-15 | Tampering | score normalization (A1) edge cases | low | mitigate | `results[0]?.score ?? 1` + `top > 0 ? r.score / top : 0` guard — empty results and zero-top-score cannot produce NaN/Infinity; test pins the [0,1] invariant |
</threat_model>
