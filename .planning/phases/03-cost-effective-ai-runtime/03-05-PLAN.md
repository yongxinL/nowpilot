    **API:**
    ```typescript
    export class ChunkBuffer {
      private buffer: string[] = [];
      private rafId: number | null = null;

      constructor(private onFlush: (text: string) => void) {}

      push(text: string): void {
        this.buffer.push(text);
        this.scheduleFlush();
      }

      flush(): void {
        if (this.rafId !== null) {
          cancelAnimationFrame(this.rafId);
          this.rafId = null;
        }
        if (this.buffer.length > 0) {
          const combined = this.buffer.join('');
          this.buffer = [];
          this.onFlush(combined);
        }
      }

      destroy(): void {
        if (this.rafId !== null) {
          cancelAnimationFrame(this.rafId);
          this.rafId = null;
        }
        this.buffer = [];
      }

      private scheduleFlush(): void {
        if (this.rafId !== null) return; // already scheduled
        this.rafId = requestAnimationFrame(() => {
          this.rafId = null;
          this.flush();
        });
      }
    }
    ```

    **Per D-06:** ChunkBuffer processes only renderer `text-delta` events. Tool/planner events flow through immediately — they do NOT go through ChunkBuffer. The AgentOrchestrator is responsible for routing events (text-delta → ChunkBuffer, all others → direct emission).

    **API:**
    ```typescript
    export class AbortManager {
      readonly rootController = new AbortController();

      createStageTimeout(ms: number): AbortSignal {
        // Creates child AbortController that aborts when either:
        // 1. Root controller aborts (user cancellation) → clears timeout, propagates root reason
        // 2. Timeout fires after `ms` milliseconds → aborts with TimeoutError
        const stageController = new AbortController();
        const timeoutId = setTimeout(
          () => stageController.abort(new DOMException('Stage timeout', 'TimeoutError')),
          ms
        );

        this.rootController.signal.addEventListener('abort', () => {
          clearTimeout(timeoutId);
          stageController.abort(this.rootController.signal.reason);
        }, { once: true });

        return stageController.signal;
      }

      cancel(reason?: string): void {
        this.rootController.abort(
          new DOMException(reason ?? 'User cancelled', 'AbortError')
        );
      }

      get isAborted(): boolean {
        return this.rootController.signal.aborted;
      }
    }
    ```

    **Per D-17:** Single root AbortController per operation. Each stage gets a child signal via `createStageTimeout`. AI SDK v4 natively accepts `abortSignal` in `generateText`/`streamText` — child signals are passed directly.

    **Per D-18 staged recovery:** Planner timeout → one-shot repair within 3s window (handled by PlannerService, not AbortManager). Executor timeout → structured error result (handled by ExecutorService). Renderer timeout → partial text or error (handled by RendererService). AbortManager provides the signal infrastructure — each service handles its own recovery.
