  <action>
    Create `ProviderRegistry` class following the KeymapRegistry pattern: class+singleton export, Map-based storage.

    **Class structure:**
    - Private `#providers = new Map<string, ProviderConfig>()` using JS private fields
    - Private `#instances = new Map<string, any>()` for lazy-created AI SDK provider instances
    - `async initialize(): Promise<void>` — loads persisted configs from `chrome.storage.local.get('np_provider_registry')`, deserializes into in-memory Map (model list only — API keys are read from providerStore at adapter-creation time, NOT stored in the registry)
    - `async persist(): Promise<void>` — serializes provider configs (without API keys) to `chrome.storage.local.set({ np_provider_registry })`
    - `registerProvider(config: ProviderConfig): Promise<void>` — validates config, stores in Map, lazy-creates AI SDK instance on first access, persists
    - `getProvider(providerId: string): { instance: any; config: ProviderConfig } | undefined` — returns cached AI SDK instance + config; if instance not cached, creates via adapter factory and caches
    - `getModelsForTier(tier: CostTier): ModelEntry[]` — filters all models across all enabled providers matching tier, sorted by provider priority
    - `listModels(): ModelEntry[]` — all models across all enabled providers
    - `listProviders(): ProviderConfig[]` — all registered providers
    - `updateModel(providerId: string, modelId: string, updates: Partial<ModelEntry>): Promise<void>` — per D-03 user override of metadata
    - `removeProvider(providerId: string): Promise<void>` — removes from Map and persists

    **API key handling:** Provider adapters create AI SDK instances with `apiKey` parameter. Read keys from `useProviderStore.getState().apiKeys[providerId]` at adapter-creation time. Keys are already encrypted at rest via EncryptedStorage. Do NOT store raw keys in ProviderRegistry.

    **Error handling:** All catch blocks call `debugLog('error', ...)` per HARD-09. `chrome.storage.local` operations wrapped in try/catch with structured error logging.

    **Export:** `export const providerRegistry = new ProviderRegistry()` singleton + `export class ProviderRegistry` for testing.
