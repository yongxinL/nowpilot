## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| npm registry → project | Untrusted packages enter the dependency tree; [SUS] packages flagged per RESEARCH.md audit |
| User message → Planner system prompt | Untrusted user input injected into LLM prompts |
| Provider API → ProviderRouter | Untrusted provider responses (model lists, errors) |
| Tool call → ExecutorService | Planner-decided tool invocations cross trust boundary |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-SC | Tampering | npm install (ai, @ai-sdk/*, jsonrepair) | high | mitigate | slopcheck + blocking human checkpoint for all 5 [SUS] packages; exact version pinning prevents floating upgrades |
| T-03-01 | Spoofing | PlannerService prompt | high | mitigate | User message placed in clearly demarcated section of system prompt; JSON mode constrains output to valid JSON; Planner system prompt is separate from user message (not concatenated raw) |
| T-03-02 | Information Disclosure | All provider API calls, debugLog | critical | mitigate | API keys read from EncryptedStorage (AES-GCM-256); AI SDK errors sanitized before logging via debugLog — never log raw HTTP responses; no API keys in user-facing error messages |
| T-03-03 | Elevation of Privilege | ExecutorService tool execution | high | mitigate | Closed-enum tool-name validation rejects unknown tools per D-12; PermissionService default-deny per D-13; dangerous tools always require permission regardless of allow list |
| T-03-04 | Denial of Service | AgentOrchestrator loop | medium | mitigate | Tier caps (1-5 planner calls max); per-stage timeouts (3s planner, 10s tool, 5s renderer); root AbortController for user cancellation; circuit breaker per-provider (3 failures/60s → 5min cooldown) |
| T-03-05 | Tampering | modelDiscovery endpoint responses | medium | accept | Model discovery responses are user-visible by design; discovery failures return empty array (no crash); user can override discovered metadata per D-03 |
</threat_model>
