**NoteMaintenance.ts (LLM-WIKI-02/03/04/08/09/10, CAT-02/03, SYNC-08, WIKI-ID-04, D-122):**

Create `src/core/notes/NoteMaintenance.ts` with:

**Staleness detection (LLM-WIKI-08):**
- `detectStaleness(note: Note): StalenessResult` — compare `note.updated` vs `Math.max(note.summaryGeneratedAt ?? 0, note.tagsGeneratedAt ?? 0)`. Return `{ noteId, isStale, lastGeneratedAt, noteUpdatedAt }`.
- `isStale` = true when `lastGeneratedAt > 0 && note.updated > lastGeneratedAt`.

**Orphan detection (LLM-WIKI-09):**
- `detectOrphans(notes: Note[]): string[]` — for each note, check `note.links.length === 0` AND `computeBacklinks(notes).get(note.id)?.length === 0`. Return orphan noteIds.
- **Algorithmic, no LLM** (D-122).

**Bulk re-analyze (LLM-WIKI-10):**
- `reanalyzeAllNotes(onProgress: (stats: BulkAnalysisStats) => void, abortSignal: AbortSignal): Promise<BulkAnalysisStats>`:
  1. Read all notes from NotesDB.
  2. Sequential loop: for each note, call `NoteTagger.analyze()` (reuse Plan 01 service).
  3. Apply gated suggestions.
  4. Call `onProgress()` after each note.
  5. Respect `abortSignal.aborted` — stop mid-batch.
  6. Return final stats `{ processed, total, tagged, categorized, summarized, errors }`.
- **User-initiated only** — no background scheduling (D-06).

**LLM-WIKI/LLM-WIKI-02 gating:**
- Read `np_notes_llm_features` from chrome.storage.local.
- `autoTag === false` → skip tag extraction in analyze calls.
- `autoCategorize === false` → skip categoryPath.
- `autoSummary === false` → skip summary.
- All false → skip NoteTagger.analyze entirely.

**WIKI-ID-04 boundary:**
- Deleting a note does NOT rewrite source bodies. Referencing edges become dangling and are moved from `links[]` back to `unresolvedLinks[]` at next save/graph rebuild (handled by existing LinkParser.demoteDangling).

**No background jobs (D-06):**
- Verify: no `setInterval`, no `chrome.alarms`, no MV3 background timers. All maintenance is user-triggered.

**UI-SPEC data contracts:**
- `StalenessResult`, `OrphanResult`, `ReanalyzeProgress` match the interfaces in UI-SPEC §"NoteMaintenance → Maintenance Surface".
- Emit `note:sync-status` events for SYNC-08 status Tag rendering.

**Object-form namespace export** per established pattern.

**Strict-clean:** Zero new `@ts-expect-error NP-STRICT` markers.
