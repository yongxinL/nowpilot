# Phase 9 — UI Design Contract

> Visual and interaction contract for Phase 9: LLM-Wiki & Filesystem Sync. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Phase nature: service-layer only.** Phase 9 ships five pure-logic service modules (NoteTagger, NoteQA, NoteChatConverter, NoteFileSync, NoteMaintenance) and a v4 IndexedDB migration. **No UI components ship in Phase 9** — the full NotesWorkspace UI (suggestion chips, backup status bar, restore modal, Ask-notes surface) lands in Phase 15.1/15.2. This contract defines the **data contracts, status enums, and exact copy strings** those Phase-15 UI components will consume, so the service layer and the UI layer stay decoupled but compatible.

## Service → UI Data Contracts

Phase 9 services expose these typed interfaces. Phase 15 UI consumes them directly — no transformation layer.

### NoteTagger → Suggestion Surface

```typescript
// Emitted via EventBus('note:suggestions') after non-blocking analyze()
interface NoteSuggestionsEvent {
  noteId: string;           // UUID (WIKI-ID-01)
  tags: string[];           // ≤NOTE_SUGGESTION_MAX_TAGS_PER_SAVE (5), confidence ≥ 0.60
  categoryPath: string | null; // e.g. "InfoTech/Database/MySQL" or null
  summary: string;          // 1-2 sentences, empty string if no summary
  staleness: {
    summaryGeneratedAt: number | null;
    tagsGeneratedAt: number | null;
    noteUpdatedAt: number;
    isStale: boolean;       // true → show "Regenerate" hint
  };
}

// Confidence gating constants (LLM-WIKI-11)
const NOTE_SUGGESTION_DISPLAY_THRESHOLD = 0.60;
const NOTE_SUGGESTION_MAX_TAGS_PER_SAVE = 5;
const NOTE_SUGGESTION_MAX_FACTS_PER_SAVE = 3;
```

**Accept/reject contract:** UI calls back into service with `acceptTags(string[])`, `acceptCategory(string | null)`, `acceptSummary(string)`, `rejectAll()`. Accepted values persist to NotesDB. Rejected values discarded, never re-suggested for same `{noteId, version}`.

### NoteQA → Ask-Notes Surface

```typescript
// Returned by NoteQA.ask(query, ctx)
interface NoteQAResult {
  answer: string;           // Markdown, balanced-tier synthesis
  citations: Array<{
    noteId: string;         // UUID, for click-to-open
    title: string;          // Human-readable, for display
    snippet: string;        // ≤200 chars, for preview
  }>;
  mode: 'ai-enhanced' | 'keyword-only';  // keyword-only = tiny tier fallback
}

// AI rerank (LLM-WIKI-05)
interface RerankResult {
  hits: Array<{ id: string; score: number }>;
  reranked: boolean;        // false if <3 results or AI search disabled
}
```

**Rendering contract:** Citations render as clickable AntD `Tag` components (color: `colorPrimary`) inside the X `Bubble` footer. Clicking opens the note in col 3. "AI-enhanced" pill renders when `mode === 'ai-enhanced'`.

### NoteFileSync → Backup Status Surface

```typescript
// Emitted via EventBus('note:sync-status') on state change
type SyncStatus =
  | { state: 'on'; folderName: string; lastSyncAt: number }
  | { state: 'off'; reason: 'no-folder' | 'permission-denied' }
  | { state: 'error'; message: string; recoverable: boolean };

// Restore preview (SYNC-10)
interface RestorePreview {
  total: number;
  new: number;
  updated: number;
  unchanged: number;
  conflicts: Array<{ noteId: string; title: string; resolution: 'create' | 'update' }>;
}
```

**Rendering contract:**
- `state: 'on'` → green `Tag` "Backup: On" + tooltip with folder name + last sync time
- `state: 'off'` → gray `Tag` "Backup: Off" + "[Configure]" link
- `state: 'error'` → red `Tag` "Backup: Error" + tooltip with error message
- Restore preview → `Modal` (E3, radius 16) with counts + `[Import]` (primary) / `[Cancel]` (ghost)

### NoteMaintenance → Maintenance Surface

```typescript
// Orphan detection (LLM-WIKI-09)
interface OrphanResult {
  noteId: string;
  isOrphan: boolean;        // true when 0 links + 0 backlinks
}

// Staleness (LLM-WIKI-08)
interface StalenessResult {
  noteId: string;
  isStale: boolean;         // updated > summaryGeneratedAt || updated > tagsGeneratedAt
  lastGeneratedAt: number;
  noteUpdatedAt: number;
}

// Bulk re-analyze progress (LLM-WIKI-10)
interface ReanalyzeProgress {
  current: number;
  total: number;
  phase: 'analyzing' | 'complete' | 'error';
  updatedCount: number;
}
```

## Service Configuration Contracts

### `np_notes_llm_features` (LLM-WIKI-02)

Persisted in chrome.storage.local. Read by services to gate LLM calls.

```typescript
interface NotesLLMFeatures {
  autoTag: boolean;         // default: true
  autoCategorize: boolean;  // default: true
  autoSummary: boolean;     // default: true
  aiSearch: boolean;        // default: true
}
```

**Gating contract:**
- `autoTag === false` → NoteTagger.analyze() skips tag extraction
- `autoCategorize === false` → NoteTagger.analyze() skips categoryPath
- `autoSummary === false` → NoteTagger.analyze() skips summary
- `aiSearch === false` → NoteQA.rerank() skipped, pure MiniSearch results
- All false → NoteTagger.analyze() not called on save at all

### `notes_backup_config` (SYNC-01)

Persisted in IndexedDB (handles non-serializable).

```typescript
interface NotesBackupConfig {
  id: 'primary';            // fixed key
  handle: FileSystemDirectoryHandle;  // non-serializable — IDB only, never chrome.storage.local
  lastSyncAt: number;       // epoch ms
}
```
