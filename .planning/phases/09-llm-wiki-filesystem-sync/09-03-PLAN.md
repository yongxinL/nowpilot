**NoteFileSync.ts — sync engine (SYNC-01…07/11, WIKI-ID-01, OKF-WIKI-01/02/03/04, CAT-04, D-119/120):**

Create `src/core/notes/NoteFileSync.ts` with the sync engine:

**Serialization (SYNC-04, OKF-WIKI-01/02/03):**
- `serializeNoteToMarkdown(note: Note, tier: string): string` — builds OKF v0.2 frontmatter object:
  ```typescript
  {
    type: note.type ?? 'Note',  // OKF-WIKI-01
    title: note.title,
    description: note.summary,  // OKF-WIKI-01
    id: note.id,                // OKF-WIKI-03 (UUID as OKF extension key)
    created: note.created,
    updated: note.updated,
    tags: note.tags,
    categoryPath: note.categoryPath,
    generated: { by: `nowpilot/${tier}`, at: new Date().toISOString() },  // OKF-WIKI-02
    status: 'stable',           // OKF-WIKI-02
  }
  ```
- Use `yaml.stringify()` for the frontmatter block. Output: `---\n${yamlBlock}---\n\n${note.content}`.
- **OKF-WIKI-04 boundary:** Do NOT emit OKF standard-markdown-link edges. Wikilinks (`[[Title]]`) stay inline in the markdown body. This is verified by test.

**File path (SYNC-04, CAT-04):**
- `sanitizeFilename(title: string): string` — replace `/ \ : * ? " < > |` with `_`.
- `buildFilePath(note: Note): string` — `{categoryPath}/{sanitizedTitle}.md` (empty categoryPath → root).

**Handle persistence (SYNC-01, D-08):**
- `getBackupHandle(db): Promise<FileSystemDirectoryHandle | null>` — read from `notes_backup_config` store, verify `handle.queryPermission({ mode: 'readwrite' }) === 'granted'` (SYNC-02).
- `persistBackupHandle(db, handle): Promise<void>` — write `{ key: 'backup_handle', handle }` to `notes_backup_config` store.
- **Never use chrome.storage.local** — handles are non-serializable (structured-cloneable only).

**Sync trigger (SYNC-03):**
- Subscribe to `NOTE_SAVED_EVENT` via EventBus.
- 50ms debounce (module-level timer) before calling `syncNoteToFilesystem()`.
- Fire-and-forget: no loading state, errors caught + debugLogged.

**Collision handling (SYNC-05):**
- Before writing, scan existing files in target folder for same basename. If collision, append `(n)` suffix: `My Note (1).md`, `My Note (2).md`, etc.

**External-change guard (SYNC-06):**
- Track `lastSyncTimestamp` per note (stored in memory or derived from note.updated).
- On sync, check `file.lastModified > lastSyncTimestamp + 2000` (2s tolerance). If true → conflict: skip write (default Skip per SYNC-06). UI will show confirm dialog in Phase 15.

**Delete-on-sync (SYNC-11):**
- On `note:deleted` event, remove the `.md` file. If the category folder becomes empty, remove it too.

**FS abstraction for testing:**
- Abstract FS operations behind `FileSystemAdapter` interface with `getFileHandle`, `writeFile`, `deleteFile`, `listFiles`, `createDirectory` methods.
- Production impl uses real File System Access API. Tests inject mock impl.
