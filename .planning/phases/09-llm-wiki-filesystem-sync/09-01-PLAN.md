## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LLM output → NoteTagger | Untrusted structured data from AI provider crosses into NotesDB storage |
| Note content → LLM prompt | User-controlled note content crosses into AI provider prompt |
| NoteTagger → MemoryEngine | Extracted memory facts cross into persistent memory store |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-P9-01 | Tampering | NoteTagger.analyze() | high | mitigate | Structured JSON schema (NoteTagResultSchema) via StructuredOutput; system prompt separated from note content; Zod validation on all LLM output |
| T-P9-02 | Information Disclosure | NoteTagger prompt | medium | mitigate | Note content is untrusted data (CTX-02); TraceRedactor applied before any debugLog call (§27.6) |
| T-P9-03 | Tampering | NMEM-02 fact routing | medium | mitigate | MemoryFacts validated by MemoryExtractor schema before MemoryEngine.upsert; primary-surface gate (isPrimaryWriter) prevents double-write |
| T-P9-04 | Tampering | Stale async suggestions | medium | mitigate | Version-check on NoteTagger response (LLM-WIKI-11): capture note.version at call time, discard if mismatched on return |
| T-P9-SC | Tampering | npm installs (yaml, @types/wicg-file-system-access) | high | mitigate | Package-legitimacy gate (RESEARCH.md audit) + blocking human-verify checkpoint before install |
