    Create `useStreamingLLM` hook with this signature:
    ```
    function useStreamingLLM(config: {
      orchestrator: AgentOrchestrator;
      onDelta: (text: string) => void;
      onComplete: (fullText: string) => void;
      onError: (message: string) => void;
      onToolCall?: (toolName: string, input: unknown) => void;
      onWaitingPermission?: (toolName: string, toolInput: unknown) => void;
      onDegradation?: (event: OrchestratorEvent & { type: 'context-degraded' }) => void;
      onContextError?: (event: OrchestratorEvent & { type: 'context-error' }) => void;
    }): { startStream: (optimizedContext: OptimizedContext, preferredProviders: string[]) => Promise<void>; abort: () => void; isStreaming: boolean; error: string | null }
    ```

    Internal implementation per D-01 and RESEARCH.md Pattern 1:
    - `useRef` for `AbortController` and `ChunkBuffer` (ChunkBuffer wraps orchestrator to rate-limit text)
    - `useState` for `isStreaming` (boolean) and `error` (string | null)
    - `startStream()`: abort existing stream if active → create AbortController → set isStreaming=true → create ChunkBuffer with onFlush calling onDelta → `for await (const event of orchestrator.runWithContext(optimizedContext, preferredProviders))` → switch on event.type: text-delta pushes to ChunkBuffer, text-complete flushes+onComplete, tool-called→onToolCall, waiting-permission→onWaitingPermission, error→flush+onError, context-degraded→onDegradation, context-error→onContextError, plan-created ignored (consumer hooks handle). Catch AbortError (DOMException name==='AbortError') → swallow silently. Catch other errors → onError. Finally: set isStreaming=false, destroy ChunkBuffer.
    - `abort()`: calls `orchestrator.cancel()` → aborts AbortController.
    - `useEffect` cleanup: calls abort() on unmount (Pitfall 2 mitigation).
    - Return `{ startStream, abort, isStreaming, error }`.

    IMPORTANT: This hook does NOT call ContextOptimizer.optimize() or MemoryEngine.assemble(). Context assembly is the consumer hook's responsibility (useChat/useAgent per D-04). The hook receives a pre-built OptimizedContext.
