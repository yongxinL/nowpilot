## Design System

| Property | Value |
|----------|-------|
| Tool | none (shadcn not applicable) |

## Spacing Scale

Ant Design v6 defaults to an 8px base unit. All values are multiples of 4.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding between text and icons, tight element spacing |
| sm | 8px | Compact element spacing, form item gaps (compact mode), list item padding (compact) |
| md | 16px | Default element padding, card body padding (compact), Bubble.List padding, form item bottom margin |
| lg | 24px | Section padding, form layout gaps, card body padding (default mode), sider item padding |
| xl | 32px | Layout gaps, page-level padding, content area margins |
| 2xl | 48px | Major section breaks, graph view container padding |
| 3xl | 64px | Page-level spacing (rare — large empty states) |

**Specific phase exceptions (compact mode — Side Panel):**
- Chat message list padding: `16px` (md) horizontal, `8px` (sm) vertical
- Sender component padding: `0 16px 16px` (md)
- Conversation sidebar width: `260px` (Full App only)
- Note editor split-pane gap: `16px` (md)
- Options form max-width: `720px` (D-09)
- Status bar height: `38px` (existing WORKSPACE_STATUS_BAR_HEIGHT)
- Nav sider width: variable (`STANDALONE_NAVBAR_WIDTH` = 240 expanded / 56 collapsed; `SIDEPANEL_NARROW_MAX_WIDTH`)

**Source:** Existing codebase `WorkspaceStatusBar.tsx` (38px bar), `StandaloneRoot.tsx` (border-radius 16px, margin 12px), RESEARCH.md §Architecture Patterns (D-09, D-13, D-22)

## Typography

Four explicit sizes, two weights. Derived from Ant Design v6 built-in token defaults and project usage patterns.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Small / Caption | 12px | 400 | 1.5 (18px) | Status bar text, metadata, timestamps, conversation previews, form helper text, secondary labels |
| Body | 14px | 400 | 1.5715 (22px) | Default body text, form labels, input text, Sender placeholder, conversation titles, note content, Bubble content, list items |
| Section Heading | 16px | 600 | 1.5 (24px) | Card titles, section headings (Options), Conversation group labels, modal titles, panel headers |
| Page Title | 20px | 600 | 1.4 (28px) | Page-level titles, empty state headings, graph view title |

**Weights used:**
- `400` (regular): Body text, small text, labels, inputs, secondary content
- `600` (semibold): Headings, titles, active nav items, primary CTAs, emphasized text

**Notes:**
- Ant Design Typography components (`Title`, `Text`, `Paragraph`) should be used for all text — do NOT use raw `<h1>`/`<p>` tags in new code (the existing page stubs do this but they are being replaced).
- `@ant-design/x-markdown` XMarkdown component renders markdown content with its own typographic defaults — no additional typography rules needed for rendered markdown.
- Monospace/code: Inherited from Ant Design's code block styles and XMarkdown's code renderer. No separate monospace token declared at this level.
- Status bar uses `11px` (Side Panel compact) or `12px` (Full App) — captured under Small (12px).

**Source:** Existing page stubs (32px stub placeholder deprecated), WorkspaceStatusBar.tsx (11-12px), Ant Design v6 default tokens: `fontSize: 14`, `fontSizeSM: 12`, `fontSizeLG: 16`, `fontSizeXL: 20`

## Color

Colors are driven by Ant Design's algorithm-generated semantic tokens. No custom hex values are used — the algorithm automatically adapts all colors for light/dark modes. The contract below references Ant Design token names with approximate light-mode equivalents for developer reference only.

| Role | Token Reference | Approximate Light | Usage |
|------|----------------|-------------------|-------|
| Dominant (60%) | `colorBgLayout` | `#f5f5f5` | Page/shell background, Side Panel background, empty areas, graph view background |
| Secondary (30%) | `colorBgContainer` | `#ffffff` | Cards, content panels, Bubble backgrounds (user/assistant), Sender container, conversation sidebar, note editor, forms, modal bodies, dropdown panels, ThoughtChain container, Options sections |
| Accent (10%) | `colorPrimary` | `#1677ff` | **Reserved exclusively for:** primary buttons (type="primary"), links, active nav item indicators, focus rings, selected states, toggle switches (active), progress indicators, permission allow buttons, streaming activity indicator dot |
| Destructive | `colorError` | `#ff4d4f` | Destructive actions ONLY: delete buttons, Popconfirm delete confirmations, error alerts, error-state ThoughtChain nodes, permission deny button, danger badge on dangerous tools |

**Accent reserved-for list (exhaustive — never used elsewhere):**
1. Primary action buttons (Save, Send, Test Connection, Allow Once/Always, Create Note)
2. Hyperlinks within content (XMarkdown rendered links, Options section cross-references)
3. Active navigation selection indicator (sider active item highlight)
4. Focus rings on interactive elements (inputs, buttons, toggles)
5. Toggle and switch active (checked) states
6. Progress/loading indicators (spinner, streaming dot)
7. Selected states (selected conversation highlight, selected note highlight)
8. Permission "Allow" action buttons
9. d3-force graph node fill for the currently selected/active node

**Surface-specific background considerations:**
- Side Panel content area: `colorBgContainer` with rounded corners (borderRadius 16px) inside `colorBgLayout` shell — same pattern as StandaloneContentWrapper
- Full App content area: `colorBgContainer` with boxShadowSecondary, borderRadius 16px, margin 12px — existing pattern from StandaloneContentWrapper
- Dark mode: All tokens automatically inverted by `darkAlgorithm`. No manual dark-mode overrides needed.

**Text colors:** Use Ant Design's semantic text tokens:
- Primary text: `colorText` (body, headings, labels)
- Secondary text: `colorTextSecondary` (metadata, descriptions, timestamps)
- Tertiary/disabled: `colorTextTertiary` or `colorTextDisabled` (placeholders, disabled states)

**Source:** `src/core/theme/antdConfig.ts` (no custom overrides → pure defaults), `StandaloneRoot.tsx` (container pattern), Ant Design v6 default token values

## State Taxonomy for UI Components

| State Type | Where Applied | Component Pattern |
|-----------|---------------|-------------------|
| Loading | Chat: streaming indicator dot, Sender loading spinner | Sender `loading={isStreaming}`, Bubble `loading` when empty content |
| Loading | Agent: ThoughtChain steps with blink animation | ThoughtChain `blink` prop on active step |
| Loading | Notes: skeleton cards during note list load | Ant Design `Skeleton` while IndexedDB reads |
| Loading | Options forms: Button loading state during save | `Button loading={isLoading}` |
| Empty | No conversations | Ant Design `Empty` component or Result with illustration |
| Empty | No notes | Ant Design `Empty` with CTA: "Create your first note" |
| Empty | No agent sessions | Descriptive empty state with prompt |
| Empty | Options sections (no providers, no MCP servers, etc.) | Inline text + CTA button |
| Error | Streaming failure (all pages) | Ant Design `Alert` or inline error with Retry action |
| Error | Provider error (Chat/Agent) | `Alert type="error"` with action buttons |
| Error | Save failure (Notes, Options) | `App.useApp().message.error()` toast |
| Error | Fatal error (all pages) | ErrorBoundary → `Result status="error"` |
| Streaming | Chat: text appearing character by character | Bubble.List in-place update + XMarkdown `streaming.hasNextChunk` |
| Streaming | Agent: ThoughtChain steps appearing/updating | ThoughtChain items pushed incrementally |
| Permission | Agent: waiting for user decision | ThoughtChain waiting-permission step (blink) + Modal.confirm simultaneously (D-05) |
| Disabled | Provider not configured (Chat/Agent) | Sender disabled with help text |
| Disabled | No model selected | Sender disabled, Provider selector shows error |
| Success | Options save, note save, test connection | `message.success()` toast |
| Aborted | Stream cancelled mid-response | Partial message remains in Bubble.List; Sender loading stops |
