<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User input → SlashCommandRegistry.parseCommand() | Untrusted text enters regex-based parser; must handle malformed input |
| User-defined templates → TemplateEngine.render() | User-supplied template strings with `{{variable}}` markers; missing vars rendered as literals |
| User-defined prompt templates → LLM | Content from PromptManager fed to ContextOptimizer; separation by section kind prevents prompt injection |
| chrome.storage.local → PermissionStore | Permissions stored as plain JSON; no encryption needed (not secrets) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-01 | Tampering | SlashCommandRegistry.parseCommand | low | accept | Regex extraction only parses command name; no eval. Malformed input returns null. |
| T-07-02 | Information Disclosure | TemplateEngine.render | low | accept | Missing variables rendered as literal `{{key}}` — no exception/leak. Variables are user-defined only. |
| T-07-03 | Spoofing | PromptManager templates → LLM | low | mitigate | Template content fed to ContextOptimizer as task_instructions section (separate from system_prompt); per RESEARCH.md no injection risk. |
</threat_model>
