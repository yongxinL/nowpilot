**Key implementation details (RESEARCH.md Pitfalls + D-06/07/08/09/10/26/28):**
1. ALWAYS `const clone = doc.cloneNode(true) as Document` before `isProbablyReaderable()` and `new Readability(clone)`. Never pass live document (Pitfall 1 — DOM mutation).
2. `isProbablyReaderable(doc)` gate first → if true, use Readability; if `article.textContent.length < 100`, discard readability result and fall back (D-06).
3. Convert Readability's `article.content` (cleaned HTML string) to markdown via `this.turndown.turndown(article.content)`.
4. Safety ceiling per D-07: if markdown exceeds ~100KB, truncate and set `extractionQuality: 'minimal'`.
5. `selectedText` from `window.getSelection()?.toString() || undefined` (D-08). Empty string → undefined.
6. Meta extraction: query `meta[name]`, `meta[property]` (og:), `meta[itemprop]`. Store both name/content pairs.
7. Field stripping (D-28): before constructing PageContext, filter out `input[type=password]`, `input[type=hidden]`, elements with class/id containing 'token'/'credential'/'secret'/'auth'. Do this by extracting only text content — `@mozilla/readability` already strips non-content markup.
8. URL blocklist (D-26): helper method checks URL protocol/starts with — `chrome://`, `chrome-extension://`, `edge://`, `about:`, `view-source:`, `devtools://`, `file://`. Also block NowPilot-owned pages using `chrome.runtime.id`. If blocked, return `metadata-only` + `minimal` quality with empty markdown.
9. `extractionType` values: `'readability'` (article via Readability), `'visible-content'` (fallback DOM text), `'metadata-only'` (blocked URL or empty page).
10. `extractionQuality` values: `'article'` (Readability success, ≥100 chars), `'generic'` (visible text fallback), `'minimal'` (truncated, blocked, or empty).

**Error handling:** Wrap Readability call in try-catch. On failure, fall back to visible text extraction and `debugLog('warn', ...)`. Never throw from `extract()` — return degraded PageContext.

    // 300ms debounce (clearTimeout + setTimeout)

**Key details:**
- Clone original methods with `.bind(history)` before wrapping (Pitfall 4: SPA router interference).

- Cleanup function restores `history.pushState`, `history.replaceState` to originals, removes event listeners, disconnects observer, clears debounce timer.

**`src/core/content/PageContextBridge.ts`** — Serialization + messaging bridge (D-02, D-03). Follow PATTERNS.md §3:

```typescript
export class PageContextBridge {
  async sendPageContextUpdate(pageContext: PageContext): Promise<void> {
    const envelope = {
      type: PAGE_CONTEXT_UPDATED,
      source: 'content-script' as const,
      payload: pageContext,
      timestamp: Date.now(),
    };
    try {
      await chrome.runtime.sendMessage(envelope);
    } catch (err) {
      debugLog('error', '[PageContextBridge] Failed to send', { error: err });
      // Do NOT throw — extraction succeeded, messaging is secondary
    }
  }
}
```

Uses `PAGE_CONTEXT_UPDATED` constant from `pageMessages.ts` (Plan 01). Send failures are logged but not re-thrown (extraction still succeeds).
