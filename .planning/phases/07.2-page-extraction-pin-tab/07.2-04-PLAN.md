**`src/core/context/ContextCompressor.ts`** — Enhance structuralExtract per D-31 (PATTERNS.md §13):

Modify the `structuralExtract()` method (lines 80-95) to also extract markdown prefix:

```typescript
private structuralExtract(context: Record<string, unknown>): string {
  const fields: string[] = [];
  if (context.title) fields.push(`Title: ${context.title}`);
  if (context.url) fields.push(`URL: ${context.url}`);
  // NEW: D-31 — include first ~200 chars of markdown for pinned tab summaries
  if (context.markdown) {
    const prefix = String(context.markdown).slice(0, 200).trim();
    fields.push(`Content: ${prefix}${String(context.markdown).length > 200 ? '...' : ''}`);
  }
  if (context.summary) fields.push(`Summary: ${context.summary}`);
  if (fields.length === 0) {
    const str = JSON.stringify(context);
    return this.heuristicTruncate(str, 300);
  }
  const result = fields.join('\n');
  const estimated = tokenEstimator.estimateTokens(result);
  if (estimated > 300) {
    return this.heuristicTruncate(result, 300);
  }
  return result;
}
```

This extracts the first 200 characters of markdown content from a PageContext object, producing lightweight summaries for pinned tabs per D-31 (Full PageContext in store, summaries for AI). The existing 300-token heuristic truncation still applies as a safety net.
