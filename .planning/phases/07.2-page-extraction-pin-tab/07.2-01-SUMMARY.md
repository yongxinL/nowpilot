## Decisions Made

- **addPinnedTab guard clauses** use Zustand `set()` with `return state` for no-op behavior at the limit — predictable and avoids unnecessary state changes. Does not throw errors (consistent with other workspace setters).
- **pageContextPayloadSchema** validates all PageContext fields including optional ones (html, selectedText, addonId) — provides HARD-05 compliance at the SW boundary before any store writes.
- **html field persistence** documented but NOT persisted to chrome.storage.local — only markdown + metadata go through the WriteJournal → chrome.storage.local pipeline to avoid quota exhaustion (Pitfall 2).
