## Spacing Scale

Uses Ant Design token system. No custom scale needed — all new components consume antd tokens via `theme.useToken()`.

| Token | Value (approx) | Usage in this phase |
|-------|--------|--------|
| `token.marginXXS` / `token.paddingXXS` | 4px | Compact icon gaps, stage indicator pill internal padding |
| `token.marginXS` / `token.paddingXS` | 8px | Chip gaps in ActionChipGroup, Welcome Card icon-text gap |
| `token.marginSM` / `token.paddingSM` | 12px | Welcome Card internal padding, branded header padding |
| `token.margin` / `token.padding` | 16px | Section gaps: branded header ↔ messages, chips ↔ Sender |
| `token.marginLG` / `token.paddingLG` | 24px | Welcome Card grid gap |
| `token.marginXL` | 32px | Major layout breaks |

Exceptions:
- **Welcome Card grid**: 2-column grid on narrow surfaces (Side Panel), 3-column on Full App. `gap: token.marginLG` (24px).
- **Action chip max-width**: 200px per chip with `text-overflow: ellipsis`. Overflow scrolls horizontally.
- **Branded header**: 48px collapsed height when dismissed; 72px expanded height with avatar + tagline.
- **Clarification chips in Bubble**: `marginTop: token.marginSM` (12px) below the question text.

## Typography

Follows Ant Design default typography token system. Declared sizes for new UI elements:

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 14px | 400 | 1.5715 (antd default) | Chat messages, clarification question text, stage indicator labels |
| Label | 12px | 400 | 1.5 | Chip text (action chips, clarification chips, follow-up chips), branded header tagline |
| Heading | 16px | 600 | 1.5 | Welcome Card titles, branded header name, "Follow up" divider label |
| Display | 20px | 600 | 1.3 | Empty-state persona greeting ("Hi, I'm NowPilot") |

**Font weight constraint:** Only two weights exported: 400 (regular) and 600 (semibold). No light (300) or bold (700).

**Persona greeting in empty state:** When welcome cards are dismissed, show:
- Primary: `fontSize: 20, fontWeight: 600, color: token.colorText` — "Hi, I'm NowPilot"
- Secondary: `fontSize: 14, fontWeight: 400, color: token.colorTextSecondary` — tagline from PersonaProfile

## Color

Base from existing `antdConfig.ts`: `colorPrimary: '#e0582e'`. All new uses follow Ant Design token system.

| Role | Token | Usage |
|------|-------|-------|
| Dominant (60%) | `token.colorBgContainer` / `#ffffff` (light) | Chat message area background, empty-state background |
| Secondary (30%) | `token.colorBgElevated` | Welcome Cards, branded header bar, stage indicator pills, action chip backgrounds |
| Accent (10%) | `token.colorPrimary` (#e0582e) | Only: **(1)** Welcome Card hover border, **(2)** active/running stage indicator dot, **(3)** branded header avatar ring, **(4)** focused Sender glow |
| Destructive | `token.colorError` (antd default) | Only: error toasts, delete confirmation buttons |

Accent reserved for: Welcome Card hover, stage indicator active state, branded header avatar, Sender focus ring. Accent is NOT used for: action chips, clarification chips, follow-up chips (these use `token.colorBorderSecondary` / `token.colorBgTextHover`).

**New component color assignments:**

| Component | Background | Border | Text | Hover |
|-----------|-----------|--------|------|-------|
| Welcome Card | `token.colorBgElevated` | `token.colorBorderSecondary` | `token.colorText` | border → `colorPrimary`, elevate shadow |
| Action Chip (quick action) | `token.colorFillSecondary` | none | `token.colorText` | `token.colorFillTertiary` |
| Action Chip (clarification) | `token.colorFillSecondary` | `token.colorBorderSecondary` | `token.colorText` | `token.colorPrimaryBg` |
| Action Chip (follow-up) | `token.colorFillQuaternary` | `token.colorBorderSecondary` | `token.colorTextSecondary` | `token.colorFillTertiary` |
| Stage indicator pill | `token.colorFillSecondary` | none | `token.colorTextSecondary` | n/a |
| Branded header | `token.colorBgElevated` | bottom: `token.colorBorderSecondary` | `token.colorText` | n/a |
| Code action button | transparent | none | `token.colorTextSecondary` | `token.colorBgTextHover` |
| Clarification divider | n/a | n/a | `token.colorTextQuaternary` | n/a |

**Dark mode:** All token references automatically invert via `darkAlgorithm`. No manual dark mode overrides needed.

## Copywriting Contract

### Primary CTA Labels

| CTA | Copy | Context |
|-----|------|---------|
| Welcome Card click | Populates Sender with card's prompt template | Each card has its own prompt derived from PromptManager templates |
| Clarification chip click | Injects chip text into Sender | Text is the option label from PlannerService's `ask_clarification` response |
| Follow-up chip click | Sends chip text as next user message | Text generated by FollowUpService |
| Quick action chip click | Populates Sender with action prompt | `"Summarize this case"`, `"Draft a work note"`, etc. |
| Code "Copy" button | Copies code block to clipboard | After copy: changes to checkmark icon for 2s |
| Code "Insert" button | `"Insert into page"` | Only shown when ServiceNow page has active textarea |
| Code "Save as macro" button | `"Save as macro"` | Opens save dialog |

### Welcome Cards Copy (6 curated capability cards)

| Card Title | Description | Prompt Template (populated in Sender) |
|------------|-------------|---------------------------------------|
| Summarize This Page | Extract key points from the current page | Summarize the content of this page. |
| Research a Topic | Search and synthesize information | Research: {topic} |
| Draft a Response | Write a professional reply or update | Draft a response to: |
| Explain Code or Errors | Understand code snippets and error messages | Explain this code/error: |
| Write a Script | Generate code for automation or analysis | Write a script that: |
| Analyze Data | Extract insights from structured data | Analyze this data: |

### Empty State Copy

| State | Copy |
|-------|------|
| Empty chat (first visit) | Welcome Cards grid with heading: **"Hi, I'm NowPilot"** (fontSize: 20, weight: 600) + subtitle: **"Your AI work co-pilot. What would you like to do?"** (fontSize: 14, weight: 400, colorTextSecondary) |
| Empty chat (dismissed) | Greeting only: **"Hi, I'm NowPilot"** + tagline (no Welcome Cards). "What can I help you with?" prompt below. |
| Empty chat (new conversation) | Same as first-visit behavior unless `welcomeCardsDismissed` flag is set. |
| Dismiss button | Subtle text button: **"Don't show again"** below card grid. Tooltip on hover: "You can re-enable suggestions from Options" |

### Error State Copy

| State | Copy |
|-------|------|
| PersonaInjector failure | Fail silently — fall back to original system prompt. Log via `debugLog`. No user-facing error. |
| FollowUpService timeout | Gracefully show no follow-up chips. No error indicator. |
| Clarification round limit reached | Proceed with best-effort attempt. Append disclaimer: **"I'll proceed with the best approach — let me know if you'd like to adjust."** |
| Code insert failed (no active textarea) | Button shows disabled state with tooltip: "No editable text area detected on the current page" |

| "Save as macro" (overwrite existing) | Ant Design `Modal.confirm` | Title: "Overwrite existing macro?" — Content: "A macro with the name "{name}" already exists. Do you want to replace it?" |

## Interaction Contracts

### Welcome Card Click
1. User clicks a Welcome Card
2. Card's prompt template is set in the Sender input
3. Sender gains focus, ready for user to edit or send
4. No auto-send — user may modify the prompt before sending
5. Card grid remains visible until user sends first message

### Clarification Flow
1. PlannerService returns `action: 'ask_clarification'` with `question` + `options[]` (2-4 items)
2. UI renders `ClarificationAction`: question text as Typography.Text, options as ActionChipGroup
3. User clicks an option chip → chip text is injected into Sender
4. User may edit before sending
5. Conversation metadata tracks clarification round count
6. After round 2, Planner proceeds with `action: 'answer'` + disclaimer

### Follow-up Suggestion Flow
1. After stream completes (ChunkBuffer done, RendererService finished)
2. `FollowUpService.generateSuggestions()` called asynchronously (fire-and-forget)
3. If eligible and generation succeeds: renders divider + "Follow up" label + 1-3 chips
4. If timeout or ineligible: no chips rendered (graceful degradation)
5. User taps a chip → sent as next user message (same as typing and pressing Enter)
6. FollowUpAction respects abort — if user starts new message before suggestions render, discard

### Quick Action Flow
1. When `workspaceStore.currentPageContext` is set (page pinned or active):
2. `QuickActionService.getActions(hostname)` returns 2-3 action objects
3. `QuickActionChips` renders as horizontal strip between message area and Sender
4. User clicks a chip → prompt populated in Sender, Sender gets focus
5. Hostname mapping is static — instant, no LLM, no loading state

### Stage Indicator Flow
1. AI call starts → ContextOptimizer assembles context → emit stage `'reading-context'`
2. PlannerService begins execution → emit stage `'planning'`
3. RendererService stream starts → emit stage `'generating'`
4. >3s without token during generation → emit slow indicator, show "Still working…" with pulse animation
5. Stream completes → all stage indicators removed
6. Agent mode: uses single "NowPilot is working…" label instead of step-by-step pills

### Code Block Actions
1. XMarkdown renders a code fence → `CodeBlockActions` overlays action buttons (top-right)
2. Buttons: Copy (clipboard icon), Insert into page (if ServiceNow textarea detected), Save as macro
3. Copy: copies code to clipboard → shows checkmark for 2s → reverts to copy icon
4. Insert: only shown when `workspaceStore.currentPageContext.hostname` matches ServiceNow AND an editable field is detected
5. Save as macro: opens macro save UI (or triggers existing macro system)

### Branded Header
1. Renders above message list when chat is empty (coexists with Welcome Cards)
2. Shows: bunny avatar (32px) + "NowPilot" (fontSize: 16, weight: 600) + tagline (fontSize: 12, colorTextSecondary)
3. Close button (×) in top-right corner dismisses the header
4. Dismissed state: 48px collapsed bar (avatar only, no text)
5. On new conversation: header reappears in full expanded state
6. Does NOT appear in Agent mode (Agent has its own ThoughtChain header)
