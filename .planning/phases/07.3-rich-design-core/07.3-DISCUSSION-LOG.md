## Area 1: Persona Personality & Architecture

### Persona Storage & Loading
- **Options:** Static config file vs Storage-backed
- **Selected:** Static config with a storage-ready service layer. `PersonaProfile.ts` as static data, accessed through `PersonaService` abstraction. Synchronous in v7.3, storage-backed in 7.4/7.5.

### PersonaInjector Prompt Integration
- **Options:** Append to system prompt vs Wrap/frame
- **Selected:** Structured PERSONA block near start of system prompt. Dedicated section with identity, values, tone, behavioral rules. Composed by prompt builder.

### Emotional Awareness
- **Options:** System prompt rules vs Keyword classifier
- **Selected:** System prompt rules only via PersonaProfile. Three explicit behaviors: frustration, celebration, error recovery.

### PersonaInjector API
- **Options:** Single inject() vs Profile object + builder
- **Selected:** Single `inject(systemPrompt: string): string` API. Internally uses prompt composer. Clean, stable contract.

### Visual Avatar
- **Options:** Sparkle icon + label vs Bunny icon
- **Selected:** Bunny SVG as AI avatar. Reuse existing asset from UserAvatarMenu.tsx. Sparkle icon remains as accent symbol.

### PERSONA Block: Fixed vs Adaptive
- **Options:** Fixed block vs Context-sensitive persona
- **Selected:** Fixed core block + optional lightweight contextual hints (user_frustrated, user_succeeded, user_corrected_ai).

### Identity Name & Tagline
- **Options:** NowPilot + co-pilot tagline vs Just "NowPilot"
- **Selected:** "NowPilot — Your AI work co-pilot." Broader than ServiceNow-only. Domain expertise in separate section.

### PersonaProfile: Data vs Data + Formatting
- **Options:** Pure data vs Data with buildPromptSection()
- **Selected:** Data-only PersonaProfile.ts. Prompt construction in PersonaInjector.

### Response Brevity
- **Options:** Concise by default vs Mirror user verbosity
- **Selected:** Concise by default with task-aware expansion.

### Tone Balance
- **Options:** Professional + approachable vs Strictly professional
- **Selected:** Professional + approachable — knowledgeable senior colleague style.

### Harmful Content Handling
- **Options:** Explicit refusal template vs Native model safety
- **Selected:** Persona-guided refusal style in PERSONA block. Native model safety handles actual refusal decisions.

### Capability Question Response
- **Options:** Structured capability list vs Natural language
- **Selected:** Structured overview mapped to Welcome Card categories.

### Emotional Awareness Granularity
- **Options:** 3 explicit rules vs Single empathy rule
- **Selected:** Three explicit behaviors matching RICH-R-06/R-07/R-08.

### Emotional Expression Format
- **Options:** Prose rules vs Structured JSON
- **Selected:** Structured data internally (PersonaProfile), prose rules externally (rendered by PersonaInjector).

### Injection Timing
- **Options:** Per-call vs Cached
- **Selected:** Per-call injection at both useChat and AgentOrchestrator.

### File Structure
- **Options:** 2-file vs 3-file
- **Selected:** Three files: PersonaProfile.ts, PersonaService.ts, PersonaInjector.ts. No separate PersonaPromptBuilder in v7.3.
