### `src/core/ai/followUp/FollowUpService.ts` (service, LLM call + heuristics)

**Analog:** `src/core/ai/pipeline/PlannerService.ts` (LLM call pattern) + `src/hooks/useChat.ts` lines 93-119 (generateTitle helper — lightweight LLM call with timeout)

**LLM call with timeout pattern** (useChat.ts lines 93-119):
```typescript
async function generateTitle(userMessage: string): Promise<string | null> {
  try {
    const controller = new AbortController();
    const timeout = setTimeout(() => controller.abort(), 3000);

    const model = await providerRouter.selectModel('haiku', []);
    clearTimeout(timeout);
    if (!model) return null;

    const { generateText } = await import('ai');
    const result = await generateText({
      model: model.instance as Parameters<typeof generateText>[0]['model'],
      prompt: `Generate a brief title...`,
      maxTokens: 16,
      temperature: 0,
      abortSignal: controller.signal,
    });
    return result.text?.trim() || null;
  } catch {
    return null; // Silently fall back
  }
}
```

**PlannerService DI + error handling pattern** (lines 18-85):
```typescript
export class PlannerService {
  constructor(private router: ProviderRouter) {}

  async plan(/* ... */): Promise<PlannerDecisionType> {
    try {
      const model = await this.router.selectModel(tier, preferredProviders, execCtx, modelId);
      // make LLM call
      // handle timeout
    } catch (err) {
      const isTimeout = err instanceof DOMException && (err.name === 'AbortError' || err.name === 'TimeoutError');
      if (isTimeout) {
        debugLog('warn', '[PlannerService] plan timed out — returning fallback');
        return FALLBACK;
      }
      debugLog('error', '[PlannerService] plan failed', { error: errorMsg });
      return FALLBACK;
    }
  }
}
```

**For FollowUpService specifically:**
- Constructor: `constructor(private router: ProviderRouter)`
- `generateSuggestions(response: string, context: { hostname: string }): Promise<FollowUpSuggestion[]>`:
  1. Run heuristic rules first (fast, synchronous)
  2. If eligible for Haiku enhancement, call LLM with 3s AbortController timeout
  3. On timeout or error, return heuristic-only results (graceful degradation)
  4. Never throw — always return an array (empty if nothing to suggest)
- Singleton: `export const followUpService = new FollowUpService(providerRouter);`
- Debug log pattern: `[FollowUpService] heuristic failed` / `[FollowUpService] LLM call timed out`
