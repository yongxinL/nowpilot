# Phase 07.3 Plan 04: Follow-up Suggestions, Stage Indicators, and Code Block Actions

**FollowUpService with heuristic+optional Haiku-tier LLM suggestion engine, FollowUpAction divider+suggestion chips, StageIndicator with context-aware pipeline-driven labels and slow-stream pulse, and CodeBlockActions with Copy/Insert/Save-as-macro on XMarkdown code fences**

## Performance

- **Duration:** ~25 min
- **Started:** 2026-07-18T10:43:30Z
- **Completed:** 2026-07-18T11:08:50Z
- **Tasks:** 3 (all TDD)
- **Files modified:** 10 (4 created, 2 source modified, 4 test files created)

## Accomplishments

- **FollowUpService** — heuristic-first suggestion generation with optional Haiku-tier LLM enhancement (3s timeout, graceful degradation to heuristic-only). Eligibility checks (100+ chars, keyword matching), response-type heuristics (summary/code/list/analysis/plan), and 9 passing tests.
- **FollowUpAction** — renders visual divider with "Follow up" label + suggestion chips via ActionChipGroup. Empty suggestions returns null. Chip click calls onSelect to send text as next user message. 3 tests.
- **StageIndicator** — replaces inline ChatPage Think switch with context-aware pipeline-driven labels: "Reading page context…" (when pinned tabs), "Planning response…" (during planner), "Generating…" (during stream), with slow-stream "Still working…" pulse animation when >3s since last token. 8 tests.
- **CodeBlockActions** — inline Copy (clipboard + checkmark 2s), Insert into page (disabled when no ServiceNow textarea detected), Save as macro buttons on XMarkdown code fences via `components` prop override. 4 tests.
- **Integration** — useChat fire-and-forgets `followUpService.generateSuggestions()` after stream completion, ChatPage renders FollowUpAction in assistant bubble footer and CodeBlockActions via XMarkdown `components` prop.

## Decisions Made

- **FollowUpService** uses private `#`-prefixed methods (`#isEligible`, `#generateHeuristics`, `#tryLLMEnhancement`) for clean separation of concerns matching PlannerService pattern
- **StageIndicator slow-stream** renders the "Still working…" subtitle outside the Think component's collapsible children for immediate visibility — Think only shows its `title` text when collapsed
- **CodeBlockActions XMarkdown integration** uses the `components` prop with a class-name check (`language-` prefix) to distinguish code fences from inline code, preventing action buttons on inline spans
- **Follow-up suggestions stored** in a `useState<Map<string, FollowUpSuggestion[]>>` keyed by message ID, not attached to messages directly — cleaner state management, cleared on conversation switch/new conversation
