## Accomplishments

- **PersonaProfile.ts** — Data-only model with `PersonaProfile` interface (identity, coreValues, languageStyle, emotionalAwareness, communicationPrinciples, safetyBoundary), `PersonaHint` interface for contextual guidance, Zod schemas for runtime validation, and `DEFAULT_PERSONA_PROFILE` constant with all RICH-R-01 attributes (D-04/D-06/D-08/D-09/D-10)
- **PersonaService.ts** — Class+singleton with `#profile` private field and `getProfile()` synchronous getter. Storage-ready abstraction for 7.4/7.5 dynamic profiles
- **PersonaInjector.ts** — Class with DI constructor (receives PersonaService), `inject(systemPrompt, hints?)` prepending a structured PERSONA block with sections: Identity, Core Values, Communication Style, Behavioral Preferences, Emotional Awareness, Safety Boundaries, and optional Context-Specific Guidance (D-07 hints)
- **BunnyAvatar.tsx** — Extracted from `UserAvatarMenu.tsx` inline SVG as reusable `React.FC<{ style? }>` component. UserAvatarMenu imports and uses BunnyAvatar — no duplicate SVG code (RICH-R-11)
- **useChat.ts injection** — Line 434 (send method) and line 685 (regenerateResponse) replace hardcoded `'You are a helpful AI assistant.'` with `personaInjector.inject(...)` (D-14)
- **AgentOrchestrator injection** — `runWithContext()` wraps `plannerSystemPrompt` with `personaInjector.inject()` so both Planner and Renderer system prompts carry the persona (D-14)

## Decisions Made

- **coreValues format:** Full descriptive strings (e.g., "Privacy-first: Never share or log user data unless explicitly configured.") instead of short labels — these inject directly into the PERSONA block for richer context
- **Synchronous inject():** PersonaInjector.inject() is synchronous — PersonaProfile is a static constant with no I/O, so async overhead is unnecessary
- **BunnyAvatar as named export:** Follows project component conventions (not default export)
- **Dual personas avoided:** AgentOrchestrator wraps plannerSystemPrompt once; both Planner and Renderer use the same injected prompt (simplest approach per plan D-14)
