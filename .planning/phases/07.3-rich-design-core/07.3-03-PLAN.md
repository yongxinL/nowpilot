<objective>
Two new interaction patterns: (1) context-aware quick-action chips appearing above the Sender when a page is pinned, derived from a static hostname→action mapping table; (2) AI-initiated clarification when PlannerService detects ambiguity, rendering question+option chips inside the assistant Bubble with tracked round limits. Both share a common horizontally-scrollable ActionChipGroup component.

Purpose: Users get instant, predictable context-aware suggestions without LLM cost (D-31). The AI asks focused questions rather than guessing on ambiguous requests (D-23/D-24).

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| QuickActionService → Sender | Static developer-defined prompt strings passed to Sender. No user data crosses this boundary. |
| PlannerService (ask_clarification) → ClarificationAction | LLM-generated option labels rendered as antd Button children — React auto-escapes, no dangerouslySetInnerHTML. |
| ClarificationAction → Sender | Option text injected into controlled Sender input. User may edit before sending. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07.3-06 | Tampering | QuickActionService hostname mapping | low | accept | Hostname→action mapping is a developer-defined static table — no user input, no LLM, no dynamic content. |
| T-07.3-07 | Tampering | ClarificationAction option chips | low | accept | Option labels come from PlannerService LLM output rendered as React text nodes via antd Button children. React and antd auto-escape — no XSS vector. |
| T-07.3-08 | Elevation of Privilege | Clarification round tracking | low | accept | Round counter is per-conversation, stored in a JS Map ref — ephemeral, no persistence. Cannot be manipulated by user to bypass round limit because it resets per conversation. |
| T-07.3-SC | Tampering | npm/pip/cargo installs | low | accept | No new packages introduced. |
</threat_model>
