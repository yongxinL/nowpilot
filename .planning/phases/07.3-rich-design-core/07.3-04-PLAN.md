    Class `FollowUpService`:
    - Constructor: `constructor(private router: ProviderRouter)` — DI for LLM access.
    - Public: `async generateSuggestions(response: string, context: { hostname: string; userMessage?: string }): Promise<FollowUpSuggestion[]>`
    
    **Step 1 — Eligibility heuristic (D-28):**
    Simple rules before any LLM call. Response is eligible if:
    - Length > 100 characters (substantive output)
    - Contains keywords indicating structured output: "summary", "code", "steps", "analysis", "report", "list", "plan", "research", "script", "error", "solution"
    - Does NOT match skip patterns: pure greeting, error message, "I don't know", short confirmation
    If not eligible, return `[]` immediately.

    **Step 2 — Heuristic suggestion generation:**
    Based on response characteristics, generate 1-2 heuristic suggestions:
    - Contains "summary" or "summarize" → "Expand on key points", "Translate this summary"
    - Contains code fences or "function"/"class"/"import" → "Explain this code line by line", "Add error handling"
    - Contains numbered list or bullet points → "Elaborate on step X", "Turn into a checklist"
    - Contains analysis/research content → "Save as note", "Find related information"
    - Generic fallback: "Tell me more about this", "Save to note"

    **Step 3 — Optional Haiku-tier enhancement (D-27):**
    - Only if the response is high-value: length > 300 chars AND matches research/planning/analysis keywords.
    - Import `{ generateText }` from `'ai'` dynamically (same pattern as `useChat.ts:106`).
    - Call `this.router.selectModel('haiku', [])` — same as `generateTitle`.
    - Build a compact prompt: `"Given this AI response: "${response.slice(0, 500)}... Suggest 1-2 natural follow-up questions a user might ask. Return as JSON array of strings."`
    - 3s AbortController timeout with `AbortError` catch (same pattern as `generateTitle`).
    - On timeout or error: `debugLog('warn', '[FollowUpService] LLM call timed out/failed — returning heuristic suggestions')`, return heuristic results only.
    - On success: parse JSON, take first 1-2 items, merge with heuristics (LLM suggestions first, heuristics after). Cap at 3 total.

    **Error handling:** PATTERNS.md §Error Handling pattern — try/catch around everything, `debugLog('warn', ...)` for non-critical failures, never throw.
    - Export singleton: `export const followUpService = new FollowUpService(providerRouter);`

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| FollowUpService LLM call → ProviderRouter | Haiku-tier suggestion generation. Response text sent to LLM — contains only AI-generated text, no user PII. |
| CodeBlockActions Copy → Clipboard | Code text written to system clipboard. User-initiated action. No automatic exfiltration. |
| CodeBlockActions Insert → Page | Code inserted into pinned ServiceNow page textarea via content script messaging. Requires active textarea detection. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07.3-09 | Information Disclosure | FollowUpService LLM call | low | accept | Follow-up generation sends AI response text (not user input) to Haiku-tier model. Response text is already public model output — no PII disclosure risk. |
| T-07.3-10 | Tampering | CodeBlockActions clipboard | low | accept | Copy operation uses `navigator.clipboard.writeText` — standard browser API with user-granted permissions. Code text is from AI-generated response, not user secrets. |
| T-07.3-11 | Tampering | CodeBlockActions insert into page | low | accept | Insert button disabled unless ServiceNow hostname detected AND content script reports editable textarea. No automatic code injection — user must explicitly click the button. |
| T-07.3-12 | Denial of Service | FollowUpService Haiku call | low | accept | 3s AbortController timeout per D-27. Fire-and-forget — non-blocking to UI (D-30). Timeout degrades gracefully to heuristic-only suggestions. |
| T-07.3-SC | Tampering | npm/pip/cargo installs | low | accept | No new packages introduced. |
</threat_model>
