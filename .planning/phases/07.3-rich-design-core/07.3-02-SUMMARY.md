## Accomplishments

- **WelcomeCardService** — Class+singleton with `getCards()` returning 6 curated capability cards. Deterministic three-tier scoring: (1) usage history from chrome.storage.local, (2) hostname-based contextual boost (servicenow.com → summarize/research, github.com → explain/write), (3) default curated order. Graceful degradation on storage failure.
- **WelcomeCards** — 6-card antd Card grid in Flex wrap layout. Loading state with Spin, card click calls `onSelectCard(templateId, promptText)`, "Don't show again" dismiss button below grid. Card prompt texts from UI-SPEC §Welcome Cards Copy.

  - `!welcomeCardsDismissed` → BrandedHeader + WelcomeCards
  - `welcomeCardsDismissed` → "Hi, I'm NowPilot" persona greeting
  - `conversationLoading` → Spin indicator (prevents WelcomeCards flash)
  - Dismiss persistence via chrome.storage.local key `np_welcome_cards_dismissed`
  - Card select populates Sender with prompt text via `setDraft`

## Decisions Made

- **Usage scores in chrome.storage.local (np_welcome_card_usage):** Simpler than UserMemoryStore for dictionary-type data (card ID → count). UserMemoryStore is designed for semantic facts with MiniSearch indexing — overkill for simple usage counters.
- **Dismiss flag in chrome.storage.local directly:** Working around RESEARCH.md A3 — UserMemoryStore.upsert() is suitable for semantic facts, not simple boolean flags. Uses `np_welcome_cards_dismissed` key following the project's `np_` prefix convention.
- **Card prompt texts are static constants in WelcomeCards.tsx:** Not fetched from PromptManager. PromptManager stores full user-editable templates with {{var}} placeholders. WelcomeCards needs fixed prompt text strings per UI-SPEC. Keeping them local makes the component self-contained and avoids async-loading delays.
- **BrandedHeader close dismisses WelcomeCards too:** Per D-18, once dismissed never shown again. Both the header close button and the "Don't show again" button set the same `np_welcome_cards_dismissed` flag.
- **Conversation loading guard as wrapper function:** Wraps switchConversation with async try/finally to ensure `conversationLoading` is always reset even if the async operation fails.
