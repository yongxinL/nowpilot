| MemoryExtractor output → MemoryEngine | Untrusted AI-generated JSON crosses here — must be Zod-validated (extractionResultSchema) before any fact is upserted |
| Non-primary surface → chrome.storage.session | Write requests from non-primary surfaces are untrusted routing messages — idempotencyKey prevents replay |
