<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Non-primary surface → MemoryEngine.extract → BroadcastBus | Write requests cross surface boundary — idempotencyKey prevents replay, type field constrains allowed operations |
| MemoryEngine.extract → UserMemoryStore → MemoryDB | Fact upserts after conflict resolution — userMemoryFactSchema validates before storage |
| MemoryEngine → ConversationMemoryStore.archive → MemoryDB | Archive operations via WriteJournal for consistency — operation type 'evict-conversation' |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-14 | Tampering | Non-primary surface write request injection | medium | mitigate | MemoryWriteRequest.idempotencyKey (UUIDv4) is deduplicated in #processedKeys Set. Request type restricted to enum ['upsert-fact', 'update-summary', 'archive-conversation']. Payload validated by type-specific schemas before execution. |
| T-05-15 | Elevation of Privilege | Non-primary surface bypassing write routing | medium | mitigate | MemoryEngine.setPrimary(false) gates ALL write operations. Non-primary surfaces call broadcastBus.emitMemoryWrite — they never access store write methods directly. |
| T-05-16 | Denial of Service | Unbounded #processedKeys Set growth | low | mitigate | Auto-cleanup at 1000 entries (evict oldest). Average extract() writes 0-5 entries per round-trip, so cleanup is infrequent. Memory cap prevents runaway. |
| T-05-17 | Denial of Service | Extraction blocking pipeline | medium | mitigate | extract() is fire-and-forget — caller uses `.catch()` without await. MemoryExtractor has maxTokens=300 cap. Retry only once. |
| T-05-18 | Repudiation | Memory write not auditable | low | accept | Non-repudiation deferred to Phase 6 (AITransactionLog). Phase 5 writes are debugLog-only. |
</threat_model>
