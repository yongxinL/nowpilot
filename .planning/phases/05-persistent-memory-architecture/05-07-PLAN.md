<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| AgentOrchestrator → MemoryEngine.extract | Pipeline trigger boundary — extraction is fire-and-forget so failures don't propagate to the user-facing pipeline |
| BroadcastBus memory write request → chrome.storage.session | Cross-surface routing boundary — single-key approach means race windows exist but idempotencyKey prevents double-processing |
| Non-primary surface → chrome.storage.session.set(np_memory_write_request) | Write request emission — MemoryWriteRequest payload carries untrusted data validated by primary surface before execution |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-19 | Denial of Service | MemoryEngine.extract blocking AgentOrchestrator pipeline | critical | mitigate | Fire-and-forget: `.catch()` without `await`. D-04 explicitly requires extraction to never block the user-facing response. Verified by test: extract called in finally but not awaited. |
| T-05-20 | Tampering | Race condition on np_memory_write_request session key | medium | mitigate | Single-key approach: if two surfaces emit simultaneously, second write overwrites first. Mitigated by: (1) idempotencyKey prevents double-processing of re-sent requests, (2) in v0.1 single-user operation, simultaneous writes from two surfaces are rare. Phase 8 (queue-based approach) is deferred. |
| T-05-21 | Information Disclosure | Memory write request payload visible in chrome.storage.session | low | accept | Memory facts are user-owned data; session storage is local to the extension (not accessible to web pages). Acceptable risk for v0.1. |
| T-05-22 | Elevation of Privilege | Non-primary surface bypassing BroadcastBus to write directly | medium | mitigate | MemoryEngine.extract() gates ALL writes on `this.isPrimarySurface` check. setPrimary(false) means never executes write directly — always emits BroadcastBus. |
</threat_model>
