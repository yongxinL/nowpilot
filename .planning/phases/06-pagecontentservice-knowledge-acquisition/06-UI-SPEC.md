## Design Contract: No UI Surfaces — Infrastructure-Only

**Phase 6 (PageContentService — Knowledge Acquisition) has ZERO user-visible UI surfaces. This is an infrastructure phase.** The full §18 create inventory is pure TypeScript core modules and tests — no `.tsx`, no components, no pages, no user-facing strings, no interaction states:

```
src/core/extraction/PageContentService.ts
src/core/extraction/apcLite.types.ts
src/core/extraction/strategies/IExtractionStrategy.ts
src/core/extraction/strategies/DefuddleStrategy.ts
src/core/extraction/strategies/ApcLiteStrategy.ts
src/core/extraction/PageContentSerializer.ts
src/core/extraction/PageIndexBuilder.ts
src/core/extraction/PageContentCache.ts
src/core/content/AxDomWalker.ts
src/core/content/PageContext.ts          (D-83 supersession — canonical PageContext types)
src/core/content/PageContextBridge.ts
src/core/content/{ContentScriptHost, SPANavigationWatcher}.ts
tests/core/extraction/*.test.ts + tests/isolation/no-content-script-ui.test.ts
```

All UI-adjacent work is explicitly **out of scope and deferred to owning phases** (06-CONTEXT.md §Deferred): surface UI extraction triggers → Phase 15 (RICH-I-05), live `get-page-content` tool registration → Phase 18 (TOL-01), diagnostics surfacing of extraction metrics → Phase 11, add-on / `/research` consumers → Phase 17, `pageContext` → `ContextOptimizer.assemble` live wiring → Phase 7. ROADMAP's `**UI hint**: yes` annotations cover only Phases 15/16/17 — Phase 6 is not a UI phase.

**Consequences for this contract (all sections below are Not Applicable by design, not by omission):**

- **No visual contract** — no spacing, typography, color, or copywriting tokens are declared for Phase 6. Executor must NOT introduce any UI, styling, or user-facing copy in this phase.
- **No interaction contract** — no CTA, empty/error state copy, or destructive-confirmation copy. Error handling is a typed runtime contract (`CONTENT_EXTRACT_FAILED` closed error code, D-91), not a UI contract; it is surfaced by Diagnostics in Phase 11.
- **The one user-adjacent guarantee is a *prohibition***: the content-script bundle must stay extraction-only, <50 KB, and free of React/AntD/defuddle/yaml (isolation grep, `tests/isolation/no-content-script-ui.test.ts`) — this is the phase's "UI" boundary and is verified by test, not by visual review.
- **Downstream UI phases consume this phase's data contracts, not its visuals**: Phase 7 consumes the `PageContext` shape; Phase 15 surfaces extraction triggers; Phase 11 surfaces extraction metrics. Those phases own their UI contracts.
