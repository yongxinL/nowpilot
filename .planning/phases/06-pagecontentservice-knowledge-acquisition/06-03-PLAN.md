- `getOrExtract(tabId: number, input: ExtractInput): Promise<ExtractResult>` — the coalescing wrapper: if an in-flight promise exists for tabId, return it (dedup — §26.4a concurrency guard); else call PageContentService.extract(input), store the entry, bump lastAccessed, and clear inFlight on settle.
- `get(tabId: number): { context: PageContext; metrics: ExtractionMetrics } | undefined` — serve + bump lastAccessed (access-recency bumping); if the entry was invalidated but an in-flight re-extract exists, AWAIT the in-flight and serve the fresh result — never a stale entry (§26.4a: 'a read arriving after invalidation but before re-extract completes must await the in-flight extraction').
- `markStale(tabId: number): void` — the unsubscribed-tab path: entry stays (or is dropped per policy) but is flagged for re-extract on next demand (D-89: unsubscribed tabs are mark-stale only — no auto re-extract).

- `evict(tabId: number): void` — same as invalidate (alias for tabs.onRemoved path) — keep both names per the §26.4a wording.
- `subscribe(tabId) / unsubscribe(tabId): void` — the declared subscription API (D-88); subscribed tabs are auto re-extracted on invalidation signals (D-89), never LRU-evicted.
- `init(): void` — idempotent boot: subscribes `chrome.runtime.onMessage` (SPA_NAVIGATION → invalidate(tabIdFromEnvelope)) and `chrome.tabs.onUpdated.addListener` (changeInfo.status === 'complete' → invalidate) + `chrome.tabs.onRemoved.addListener` (evict).
