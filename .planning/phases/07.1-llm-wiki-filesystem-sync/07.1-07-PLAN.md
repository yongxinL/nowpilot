    **Step B — Add "Restore from folder" section in the Import card:**
    Add a new Card or section divider within the existing Import section. Pattern follows the existing import UI pattern in the file.

    ```tsx
    <Card title="Restore from Backup" size="small" style={{ marginTop: 16 }}>
      <Typography.Paragraph type="secondary">
        Restore notes from a previous filesystem backup. Notes will be merged with your existing notes.
      </Typography.Paragraph>
      <Button
        icon={<FolderOpenOutlined />}
        onClick={handleRestoreFromFolder}
        loading={restoreLoading}
      >
        Restore from folder
      </Button>
    </Card>
    ```

    **Step C — Add state and handler:**
    ```typescript
    const [restoreLoading, setRestoreLoading] = useState(false);

    const handleRestoreFromFolder = async () => {
      setRestoreLoading(true);
      try {
        const result = await noteFileSync.importFromFolder();
        if (!result) { setRestoreLoading(false); return; } // user cancelled picker

        const { preview, notes } = result;

        // Show preview modal per SYNC-10
        Modal.confirm({
          title: 'Import Preview',
          content: (
            <div>
              <p>Found <strong>{preview.total}</strong> notes:</p>
              <ul>
                <li>{preview.new} new</li>
                <li>{preview.updated} updated</li>
                <li>{preview.unchanged} unchanged</li>
              </ul>
              <p>Existing notes not in backup will be preserved.</p>
            </div>
          ),
          okText: 'Import',
          cancelText: 'Cancel',
          onOk: async () => {
            const count = await noteFileSync.executeImport(notes);
            message.success(`Imported ${count} notes`);
          },
        });
      } catch (err) {
        message.error('Failed to read backup folder');
        debugLog('error', '[ImportExportSection] restore failed', { error: err });
      } finally {
        setRestoreLoading(false);
      }
    };
    ```

    - Import `Modal` and `message` from `antd` (or use `App.useApp()` hook for message)
    - Per SYNC-09: import is additive — existing DB notes not in backup are NOT deleted. The preview modal ensures user consent per SYNC-10.
