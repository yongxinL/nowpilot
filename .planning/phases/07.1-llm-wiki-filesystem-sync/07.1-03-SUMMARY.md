## Decisions Made

- **50ms trailing-edge debounce** for sync() prevents rapid-save burst issues (Research Pitfall 5 mitigation). Multiple rapid saves for the same note collapse to one write — the last save wins.
- **Collision resolution** uses try/catch on `getFileHandle()` with incrementing suffix names (`My Note.md` → `My Note (1).md`) rather than iterating directory entries. Simpler, avoids async generator complexity.
- **External change detection** compares `file.lastModified` against `note.updated + 2000ms` tolerance. Returns `{ conflict: true }` so the caller can show an overwrite dialog. The 2s tolerance prevents cloud-sync false positives per SYNC-06.
- **Orphan detection** checks both sides: no outgoing wikilinks (from note content) AND no incoming backlinks (from precomputed backlinks map). This ensures a note that links to nothing AND is linked by nothing is truly orphaned.
- **Import preview** is computed before any DB writes. The actual upsert is a separate `executeImport()` call that returns all notes so the caller can rebuild MiniSearch (per Research Pitfall 3).
