    This component combines `Input.Search` with inline `Bubble` display for ephemeral RAG Q&A.

    Props: `{ linkParser: LinkParser (pre-imported); allNotes: Note[] }`

    State:
    - `query: string` — current search input
    - `answer: { text: string; citations: Citation[] } | null` — RAG result (ephemeral React state per D-15)
    - `loading: boolean` — loading spinner state
    - `error: string | null` — error display

    Flow:
    1. User types question in `Input.Search` (placeholder: "Ask your notes...")
    2. On submit: set loading=true, call `noteQA.ask(query, allNotes, linkParser)`
    3. On result: set answer with text + citations, clear error. Result is rendered inline below the input.
    4. On error: set error message, log with debugLog
    5. Answer renders as `@ant-design/x` `<Bubble placement="start" content={answer.text} />` — ephemeral, not saved
    6. Citations render below the Bubble as AntD `<Tag color="blue" onClick={() => onSelectNote(citation.noteId)}>` for each citation — clickable, navigates to source note. Add `onSelectNote` callback prop for navigation.

    **New props needed:** Add `onSelectNote?: (noteId: string) => void` to allow parent (NotesPage) to handle navigation.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User → TagSuggestions | User clicks accept/reject on LLM-suggested tags — user is gatekeeper (D-13) |
| User → AskNotesInput | User types natural language query — search input crossed into LLM prompt |
| User → NotesSection | User configures LLM feature toggles and triggers backup/analysis — feature flags determine whether LLM calls happen |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-7.1-14 | Spoofing | AskNotesInput — LLM-generated citations | medium | mitigate | Citation Tags only navigate to existing notes (by noteId). Click handler verifies note exists before navigation. LLM-fabricated citations with non-existent noteIds are filtered out — Tag renders without onClick for invalid ids. |
| T-7.1-15 | Tampering | NotesSection — chrome.storage.local toggles | low | accept | Feature toggles stored in same-origin chrome.storage.local. Toggle values are booleans with defaults. Malformed values reset to defaults on load. No sensitive data — toggles only control whether LLM features activate. |
| T-7.1-16 | Information Disclosure | AskNotesInput — note content in LLM prompt | medium | mitigate | Note snippets sent to LLM via NoteQA.ask() are truncated to 500 chars. Answer is ephemeral (React state) — not persisted. User's chosen provider handles the data; privacy impact is the same as any chat message. |
| T-7.1-17 | Denial of Service | NotesSection — bulk analyze | low | accept | "Re-analyze all notes" is user-initiated per D-07. Notes are processed sequentially, not in parallel. User can navigate away to cancel. Progress tracking prevents lock-up. No automatic triggers. |
</threat_model>
