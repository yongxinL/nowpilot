<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| NotesPage → NoteTagger | Note content sent to Haiku-tier LLM for analysis — user's note content crosses into external API |
| NotesPage → NoteFileSync | Note content written to user's filesystem — user explicitly set backup folder |
| SaveToNoteDialog → NoteChatConverter | Conversation messages + memory context sent to Haiku-tier LLM |
| ChatMessage → SaveToNoteDialog | Assistant message content + surrounding context passed for note conversion |
| NotesPage → NoteQA | Note snippets sent to Flash-tier LLM for RAG synthesis |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-7.1-20 | Information Disclosure | NotesPage save pipeline — note content to LLM | medium | accept | Note content sent to LLM when auto-tagging is enabled. This is a core feature (LLM-WIKI-01). User can disable via NotesSection toggles (LLM-WIKI-02). LLM call uses user's own configured provider — data leaves the machine to their chosen endpoint. This is consistent with all other LLM features in NowPilot (chat, agent, memory). |
| T-7.1-21 | Tampering | NotesPage — external change dialog bypass | low | accept | SYNC-06 shows confirm dialog for overwrite detection. User can click "Overwrite" or "Skip". If dialog is dismissed, sync proceeds without write (safe default). This is a UX feature, not a security boundary. |
| T-7.1-22 | Spoofing | SaveToNoteDialog — LLM-generated content | low | mitigate | LLM-generated draft is pre-filled for user review per D-13. User edits before saving. No automatic save. The "Save" button is always under user control. Content is rendered via NotePreview (XMarkdown) which provides safe markdown rendering. |
</threat_model>
