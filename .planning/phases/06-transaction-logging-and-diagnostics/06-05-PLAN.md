   - TRANSACTION_MAX = 5000, TRANSACTION_RETENTION_MS = 30 * 24 * 60 * 60 * 1000
   - NORMAL_TRACE_MAX = 2000, NORMAL_TRACE_RETENTION_MS = 14 * 24 * 60 * 60 * 1000
   - DIAGNOSTIC_TRACE_MAX = 500, DIAGNOSTIC_TRACE_RETENTION_MS = 7 * 24 * 60 * 60 * 1000
   - ERROR_MAX = 1000, ERROR_RETENTION_MS = 30 * 24 * 60 * 60 * 1000

2. pruneNow(db: AITransactionLogDB): Promise<void> — iterates over all trace stores, checks count limit then time limit. For count-based pruning, sorts by severity then timestamp, keeps failures + newest successes up to max. **D-33 sampling:** detailed success traces capped at 500 (NORMAL_TRACE_MAX=2000 accommodates this); lightweight transaction metadata for older successes retained per TRANSACTION_RETENTION_MS. Failures/warnings/retries/fallbacks/aborted/CRITICAL always fully preserved. Uses db.getTotalCount(), db.queryTransactions(), db.deleteTraces().

3. scheduleDebouncedPrune(): void — sets a 30-second debounce timer. If called while timer is active, resets timer. If pruning is in progress (pruningInProgress flag), queues one additional run after completion. Never runs synchronously.

4. startPruning(db: AITransactionLogDB): void — calls pruneNow(db) immediately, then sets 5-minute interval. Stores interval ID for cleanup.

5. Wire to AITransactionLog: import { schedulePrune } from ./AITransactionLog and assign schedulePrune = scheduleDebouncedPrune. This connects the hook declared in 06-04.

Also replace the scaffold in pruning.test.ts with 5 real tests using mocked AITransactionLogDB.
