  <action>
Create export.ts with three exported functions:

1. exportSingleTrace(operationId: string, privacyMode?: boolean): Promise<Blob>
   - Call aiTransactionLogDB.getTraceTree(operationId)
   - If privacyMode, strip content fields from traces (prompt content, tool I/O, memory content)
   - Redact via traceRedactor.redactObject() on the tree
   - Return JSON.stringify as Blob with type application/json

2. exportTraces(options: ExportOptions, privacyMode?: boolean): Promise<Blob>
   - Call aiTransactionLogDB.queryTransactions with filters from options
   - For each transaction, call getTraceTree to get full trace
   - If privacyMode, strip content fields
   - Redact all traces via traceRedactor
   - Create JSZip instance: import JSZip from 'jszip'
   - Add each trace tree as transaction_<id>.json
   - Build manifest.json per D-18 format with: export_version: '1.0', generated_at: ISO string, extension_version from chrome.runtime.getManifest().version, transaction_count, date_range from options, applied_filters, included_trace_types, redaction_version: '1.0', trace_verbosity from options or 'NORMAL', privacy_mode
   - Return zip.generateAsync({ type: 'blob', compression: 'DEFLATE' })

3. buildManifest(options: ExportOptions, count: number, privacyMode: boolean): ExportManifest
   - Construct manifest object per D-18 spec

Also export a downloadBlob(blob: Blob, filename: string): void helper that uses URL.createObjectURL + anchor click for browser download trigger.

Use the TraceRedactor singleton (traceRedactor.redactObject) to redact all trace data before JSON serialization. Privacy mode applies additional content stripping (removes prompt content, tool I/O fields entirely, not just redacted).
  </action>
