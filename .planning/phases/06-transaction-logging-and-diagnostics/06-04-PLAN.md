  <action>
Create AITransactionLog class with constructor DI: db (AITransactionLogDB), redactor (TraceRedactor), writeJournal (WriteJournal).

Implement 5 public methods:

1. start(operationId: string, execCtx: ExecutionContext): Promise<void>
   - Build minimal AITransaction: id=operationId, status='started', startedAt=Date.now(), verbosity=execCtx.verbosity, privacyMode=execCtx.privacyMode, extract workspaceId/conversationId from operationId pattern or set to empty strings (will be populated by AgentOrchestrator in 06-06)
   - Call db.logTransaction(tx)

2. complete(operationId: string, collector: TraceCollector): Promise<void>
   - Compute severity as worst among all events (D-32): CRITICAL > ERROR > WARNING > INFO > DEBUG
   - Build AITransaction update: status='completed', endedAt=Date.now(), durationMs, severity
   - Call this.close(operationId, collector, updatedTx)

3. fail(operationId: string, error: unknown, collector: TraceCollector): Promise<void>
   - Compute severity (at minimum ERROR, worst among events may be CRITICAL)
   - Build AITransaction update: status='failed', endedAt=Date.now(), durationMs, errorCode=(error instanceof Error ? error.message : String(error)), severity
   - Call this.close(operationId, collector, updatedTx)

4. private close(operationId: string, collector: TraceCollector, finalTx: Partial<AITransaction>): Promise<void>
    - Get all events: collector.getAllEvents()
    - TRUNCATE payload content per D-34 before redaction:
      * PromptTrace content fields (tokenBreakdown context, raw text): cap at 2KB per section for NORMAL verbosity, 8KB for DIAGNOSTIC
      * ToolTrace input/output fields: cap at 4KB per field for NORMAL, 16KB for DIAGNOSTIC
      * Use String.prototype.slice(0, maxBytes) with a helper truncateToBytes(str, maxBytes): string that respects UTF-8 byte boundaries
      * Always set trace.truncated = true when truncation was applied
    - Redact all events: iterate events, call redactor.redactObject() on each event's data AFTER truncation
    - Begin WriteJournal: writeJournal.begin('transaction-log-batch', { transaction_log_transactions: operationId }, steps)
    - Write steps: update transaction, then write each trace type to respective store
    - Mark completed: writeJournal.markCompleted(journal.id)
    - Clear collector: collector.clear()
    - Schedule prune: call scheduleDebouncedPrune() from pruning.ts (import will resolve in 06-05, use conditional import or declare as external function)

5. static async recoverOrphanedTransactions(db: AITransactionLogDB): Promise<void>
   - Query transactions with status 'started' or 'streaming'
   - Update each: status='aborted', endedAt=Date.now(), severity=Severity.WARNING
   - Log recovery count via debugLog

Export both class and singleton: export const aiTransactionLog = new AITransactionLog(aiTransactionLogDB, traceRedactor, writeJournal);

For scheduleDebouncedPrune(), declare as a module-level function reference that can be set externally (pruning.ts in 06-05 will assign it). Pattern: export let schedulePrune: (() => void) | null = null;
