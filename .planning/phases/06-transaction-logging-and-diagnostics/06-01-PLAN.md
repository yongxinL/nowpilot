## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| service to TraceCollector | In-memory event push, no serialization, same JS context |
| TraceCollector to AITransactionLog.close() | All accumulated events passed for redaction before persistence |
| AITransactionLog to TraceRedactor to IndexedDB | All data passes through redaction middleware before write |
| IndexedDB to DiagnosticsPanel | Read path for UI display, all data already redacted at write time |
| Export to file download | Data exfiltration path, must pass TraceRedactor + Privacy Mode |
