  <action>
Create TraceRedactor class following class+singleton export pattern. No constructor dependencies.

Define private patterns array as module-level constant (not instance property, for testability):
- Regex: /sk-[A-Za-z0-9_-]+/g, placeholder: [REDACTED:API_KEY]
- Regex: /key-[A-Za-z0-9_-]+/g, placeholder: [REDACTED:API_KEY]
- Regex: /Bearer\s+[A-Za-z0-9._-]+/gi, placeholder: [REDACTED:BEARER_TOKEN]
- Regex: /JSESSIONID=[^;\s]+/gi, placeholder: [REDACTED:JSESSIONID]
- Regex: /sysparm_ck[=:]\s*[^&\s]+/gi, placeholder: [REDACTED:sysparmCK]
- Regex: /g_ck[=:]\s*[^&\s]+/gi, placeholder: [REDACTED:g_ck]
- Regex: /X-MCP-Auth-[A-Za-z0-9._-]+/gi, placeholder: [REDACTED:MCP_AUTH]

Implement three methods:
1. redact(value: string): Applies all patterns sequentially to string input
2. redactObject<T extends Record<string, unknown>>(obj: T): Creates shallow copy, applies redact() to every string-typed property value
3. redactValue(value: unknown): Dispatches by typeof — string calls redact, object (non-null) calls redactObject, array maps over elements recursively, primitives pass through

Export both class and singleton: export const traceRedactor = new TraceRedactor();

Scope: These are the primary redaction patterns for AI/provider auth. Additional patterns for raw body/clipboard/case body content are applied at the AITransactionLog layer (06-04) by checking specific field names, not as generic regex — those paths handle data type-aware truncation (D-34).
